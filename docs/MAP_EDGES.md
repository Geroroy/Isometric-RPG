# 맵 경계 처리 (코러산트 허브)

## 다른 아이소메트릭 게임은 맵 끝을 어떻게 처리하나

| 게임 | 경계 처리 | 핵심 |
|---|---|---|
| Diablo II / Diablo III·IV | 실내는 벽·절벽 타일로 닫고, 야외는 지형(절벽·물·숲)이 빙 둘러싼다. 맵 밖은 같은 지형의 "장식 타일"이 화면 끝까지 이어진다. 카메라는 플레이어 중심이지만 맵 가장자리 바깥도 그려져 있어 검은 빈칸이 보이지 않는다. | 경계 = 넘을 수 없는 지형. 보이는 영역보다 그려진 영역이 넓다. |
| Diablo III 하늘 지역 (아리앗 분화구, 천상의 요새) | 떠 있는 플랫폼 아래로 **플랫폼 옆면**이 보이고, 그 아래는 **시차가 있는 배경 레이어**(구름·먼 탑)로 채운다. | 낭떠러지는 "빈칸"이 아니라 "아래가 보이는 깊이". |
| Bastion / Hades (Supergiant) | 땅 조각이 허공에 떠 있고, 가장자리 아래로 **두꺼운 흙·돌 단면**을 그린 뒤 배경으로 사라진다. 배경은 단색이 아니라 천천히 움직이는 원경. | 단면(두께) + 원경. |
| Transistor (Supergiant) | 미래 도시 클라우드뱅크. 갈 수 없는 쪽은 **건물 정면과 그 너머 도시 원경**으로 막는다. | 도시 = 경계도 건물. |
| Shadowrun Returns / Dragonfall | 사이버펑크 도시. 맵 끝은 **건물 벽·담·차량·쓰레기**가 막고, 그 너머는 어둠 속 실루엣과 네온. | 소품으로 "막힌 골목"을 만든다. |
| Disco Elysium | 카메라가 **맵 영역 안에 묶여** 있어 맵 바깥이 화면에 거의 안 들어온다. 가장자리는 손으로 그린 배경이 화면 밖까지 이어진다. | 카메라 클램프 + 배경 그림의 여유분. |
| Baldur's Gate / Pillars of Eternity | 미리 그린 배경 한 장. 걸을 수 있는 영역보다 그림이 크고, 카메라 스크롤이 그림 끝에서 멈춘다. | 카메라 클램프. |
| XCOM 2 / Commandos | 도시 맵 끝에 **건물·담·바리케이드**, 그 바깥은 낮은 디테일의 도시 블록이 계속된다(실루엣·조명만). | 플레이 영역 밖에도 "계속되는 도시". |
| Star Wars: Galactic Battlegrounds / Empire at War 지상전 | 코러산트 맵 끝을 **건물 지붕과 무한히 이어지는 도시 원경**으로 처리. | 코러산트는 "땅"이 없다 — 어디를 봐도 건물. |

공통 원칙 네 가지:
1. **보이는 곳에 빈칸이 없다.** 플레이 영역 밖도 무엇인가로 채워져 있다(지형, 건물, 원경).
2. **경계는 세계 안의 사물이다.** 벽·절벽·건물·소품이 막고, "보이지 않는 벽"은 없다.
3. **낭떠러지는 깊이로 보여준다.** 가장자리 아래 단면(옆면) → 대기 원근(안개) → 시차 원경.
4. **카메라를 맵 안에 묶는다.** 가장자리에 서도 화면 절반이 바깥이 되지 않게.

## 코러산트에서의 고증 (영화·애니메이션 화면)

- 코러산트는 행성 전체가 도시라 "땅의 끝"이 없다. 플랫폼은 **탑의 꼭대기나 중간 테라스**이고, 그 아래는 탑의 정면이 수 km 이어진다
  (『클론의 습격』 추격전, 『시스의 복수』 오프닝, 『클론전쟁』 S1 "Hostage Crisis", S5 "Shades of Reason" 하층).
- 상층: 황혼빛 보라·주황 안개, 따뜻한 창문 띠, 비행 차선과 붉은 항공 경고등.
- 하층: 낮은 청록·녹색 스모그, 드문드문한 창과 네온, 김.
- 플랫폼 테두리에는 밝은 립(난간 대신 금속 테두리)과 그 바로 아래 붉은 경고등.

## 구현

| 원칙 | 코드 | 내용 |
|---|---|---|
| 낭떠러지 = 탑의 옆면 | `terrain.js` `facade()` | 낭떠러지 픽셀마다 화면 위쪽(−x, −y 대각선)으로 거슬러 올라가 가장 가까운 플랫폼 타일을 찾고, 그 거리로 **림 아래 깊이 D**를 계산(D = k·2·HALF_H / Z_PX). 그 깊이에 맞춰 **탑 정면**을 그린다: 밝은 립 → 그늘 → 붉은 경고등 → 1.5타일 간격 기둥과 0.55유닛 간격 층 슬래브 사이의 **창문 띠**(상층 = 따뜻한 흰·호박, 하층 = 네온·호박) → 대기 안개로 잠기고 → 4.5~8유닛 아래에서 투명. 왼쪽 아래를 향한 면은 밝게, 오른쪽 아래 면은 그늘. 청크를 구울 때 한 번만 계산(매 프레임 비용 0). |
| 원경 = 계속되는 도시 | `cityBackdrop.js` | 지형이 비워 둔 곳에 3층 시차 원경(배율 0.1 / 0.22 / 0.38): 아이소 탑의 지붕·정면·창문 점·첨탑·붉은 경고등. 상층은 황혼 보라 안개, 하층은 청록 스모그. 층마다 384px 타일 캔버스를 미리 그려 프레임당 그라데이션 1회 + drawImage 몇 번. 비행 차선(기존 `traffic`)은 그 위를 지나간다. |
| 테두리 | `terrain.js` | 낭떠러지에 닿는 타일 가장자리에 밝은 금속 립(카메라를 향한 쪽은 진하게, 먼 쪽은 얇게). |
| 경계 = 사물 | `data/undercity.json` | 북쪽은 아파트 모듈·파이프·스팀 벤트 벽, 동서는 모듈 벽과 막힌 골목(압축기·버려진 스피더), 남쪽만 낭떠러지(탑의 옆면). 상층은 북쪽 사무 블록 벽, 서쪽 스택, 남쪽 테라스 가로등과 간판. |
| 카메라 클램프 | `renderer.js` `camRegion()` + `world.camRegions` | 시야 중심을 지금 있는 층의 화면 상자 안쪽으로 묶는다(좌우 22 %, 위 24 %, 아래 30 % 여유). 가장자리에 서도 낭떠러지가 화면 절반을 넘지 않는다. 컷신 카메라(`camFocus`)는 묶지 않는다. |

검증: `tools/qa/hubshot.mjs`(코너·테라스·남쪽 림·만), `tools/qa/smoke.mjs`(전체 흐름 오류 0), `tools/qa/undercity_ascii.mjs`(도달성).
