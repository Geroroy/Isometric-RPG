# 코러산트 하늘 교통 (에어스피더)

코러산트의 차선(`world.traffic`)을 따라 흐르던 **빛줄기를 에어스피더 스프라이트로 바꾼** 시스템과, 먼 도시 위를 지나는
배경 교통. 스프라이트는 첨부 시트 `CATEGORY 4: VEHICLES & CRAFT`(`reference/unsorted/image_2.png`)에서만 잘라 쓴다.

> 요청은 Unity C#(`CoruscantSkylineTraffic.cs`, `TrafficVehicleController.cs`) 형식이었지만 이 게임은 브라우저용
> Vite + JavaScript라서, 같은 구조를 게임 코드로 구현했다: 매니저 = `SkylineTraffic` / `LaneTraffic`,
> 차량 컨트롤러 = `TrafficVehicle` / `LaneCar`(`src/gfx/skylineTraffic.js`).

## 구성

| 깊이 | 구현 | 어디에 그리나 | 그래픽 |
|---|---|---|---|
| 먼 배경 | `SkylineTraffic` | 배경(`cityBackdrop.js`)의 가운데 탑 층과 가장 가까운 탑 층 사이, 지형보다 먼저 | 반 크기 아틀라스(`traffic_half.png`, 미리 박스 필터로 축소) |
| 낭떠러지 차선 | `LaneTraffic` 'drop' | 월드의 차선(플라자와 언더시티 사이 낭떠러지, 맵 가장자리 세로 차선)을 **플랫폼 가장자리 바로 아래 높이**로 내려, 소품·유닛과 함께 깊이 정렬 | 원본 크기 1:1 |
| 머리 위 차선 | `LaneTraffic` 'over' | 언더시티 거리 위 높은 차선, 모든 것 위에(예전 빛줄기 자리) · 거리 바닥에 불빛이 쓸고 지나감 | 원본 크기 1:1, 모두 엔진 궤적 |

## 프리렌더 그대로 (1차 버전에서 고친 것)

직접 플레이한 결과(갑자기 허공에서 나타남, 지그재그, 깨진 스프라이트, 진행 방향과 다른 모습, 프리렌더처럼 보이지 않음)를 받고
고친 내용:

- **스프라이트**: 시트에서 **떠 있는 기체만** 쓴다(스우프·레이서, 에어택시·고급 에어스피더, 각진 에어카, 건십·경찰정·셔틀 — 20종).
  바퀴 달린 차·트럭(시트의 대부분)은 하늘에서 어색해서 뺐고, 반대 방향을 보는 카트 하나와 잔해·위/옆/뒷모습도 뺐다.
  시트에 그려진 **바닥 그림자를 잘라내고**(윤곽에서 닿는 어둡고 평평한 무채색 픽셀을 벗겨 냄), 외곽선은 시트의 회색과의 거리로
  알파를 주고 회색을 빼서(매팅) 회색 테두리 없이 깨끗하게 했다.
- **그대로 그린다**: 실행 중에 크기를 바꾸거나(스무딩) 색을 덮지 않는다 — 가까운 차는 1:1, 먼 차는 미리 줄여 둔 반 크기 아틀라스.
  (아틀라스의 모든 스프라이트를 짝수 좌표에 두어 반 크기에서도 정확히 맞는다.)
- **직선**: 베지에 곡선·좌우 흔들림·위아래 흔들림을 모두 없앴다. 차선은 등각 축(월드 x 또는 y) 위의 직선이고, 차의 화면 위치는
  차선 시작점에서 정수 픽셀 단위 2:1 계단(아래로 1픽셀마다 옆으로 2픽셀)으로 정해져 떨림이 없다.
- **허공에서 튀어나오지 않음**: 차선을 레벨 양 끝 너머로 30칸씩 늘려, 차는 항상 화면 밖에서 들어와 화면 밖으로 나간다.
  풀(260대)이 차선을 다 채울 만큼 커서 화면 안에서 생겨나는 일이 없다.
- **방향**: 시트의 기체는 모두 왼쪽 아래를 본다. 월드 +y 차선(화면 왼쪽 아래로)은 그대로, +x 차선(오른쪽 아래로)은 좌우 반전.
  뒷모습이 없으므로 모든 차선은 카메라 쪽(화면 아래쪽)으로 흐른다. 엔진 궤적은 줄기의 머리를 기체 뒤쪽 점에 맞춰 뒤로 뻗는다.

## 움직임

- 속도: 차급마다(스우프 1.35 > 크루저 1.12 > 통근 1 > 화물 0.7, 차선 속도에 곱함), 차마다 ±10%. 앞차가 느리면 따라 줄이고
  4.5칸 안으로는 붙지 않는다(겹쳐 지나가지 않음).
- 스폰: 지수분포 간격(박자 없음), 직전 차가 입구를 비운 뒤에만. 레벨을 열 때 이미 흐르도록 미리 채운다.
- 먼 배경: 같은 2:1 직선으로 화면을 가로지르며, 화면 밖에서 시작해 화면 밖에서 끝난다.

## 직접 플레이 검사

`node tools/qa/trafficplay.mjs <out_dir> [spot] [seconds]` — 게임을 1/60초씩 진행하면서 모든 차선 차의 그려진 화면 위치를 기록하고
(카메라 이동은 빼고), **화면 안에서 갑자기 나타난 차**, **진행 방향이 뒤집힌 걸음(지그재그)**, **멈췄다 튀는 차**를 센다.
6프레임마다 화면을 저장해 눈으로도 본다. 기준: 모두 0.

## 설정 방법 (엔진 설정 대응)

| Unity라면 | 여기서는 |
|---|---|
| Sorting Layer / Order | 그리는 순서: `cityBackdrop.js`의 탑 층 루프 안(`TIERS[i].after`), `renderer.js`의 깊이 정렬 목록(`put(…, car)`), 마지막 `drawTraffic` |
| 프리팹 · 스프라이트 풀 | `public/sprites/traffic/traffic.png`, `traffic_half.png` + `traffic.json`(기체마다 위치·크기·차급·`rear`/`nose`) ← `python3 tools/sprites/traffic/extract.py`(`--contact out.png`로 조각 번호표) |
| 차급 분류 | `extract.py`의 `CLASS`(조각 번호 → swoop / cruiser / commuter / cargo) |
| 레이어 파라미터 | `skylineTraffic.js`의 `TIERS`(먼 배경: 시차 `f`, 풀 `max`, 스폰 `rate`, 높이 `band`, 속도), `LaneTraffic`의 `EXT`·`POOL`·`LEN`, 낭떠러지 차선 높이 |
| 차급 속도 | `CLASSES`의 `pace`(차선 속도에 곱함), 궤적 확률 `trail` |
| 차선 경로 | `src/world/worldgen.js`의 `this.traffic`(x0, y0 → x1, y1, 높이 z, 속도, 평균 간격, `over`) |
