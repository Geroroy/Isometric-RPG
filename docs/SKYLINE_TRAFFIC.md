# 코러산트 하늘 교통 (에어스피더)

코러산트의 차선(`world.traffic`)을 따라 흐르던 **빛줄기를 에어스피더 스프라이트로 바꾼** 시스템과, 먼 도시 위를 지나는
배경 교통. 스프라이트는 첨부 시트 `CATEGORY 4: VEHICLES & CRAFT`(`reference/unsorted/image_2.png`)에서만 잘라 쓴다.

> 요청은 Unity C#(`CoruscantSkylineTraffic.cs`, `TrafficVehicleController.cs`) 형식이었지만 이 게임은 브라우저용
> Vite + JavaScript라서, 같은 구조를 게임 코드로 구현했다: 매니저 = `SkylineTraffic` / `LaneTraffic`,
> 차량 컨트롤러 = `TrafficVehicle` / `LaneCar`(`src/gfx/skylineTraffic.js`).

## 세 개의 깊이 (요청의 Layer 1~3)

| 요청 | 구현 | 어디에 그리나 | 크기 · 속도 |
|---|---|---|---|
| Layer 3 깊은 배경 | `SkylineTraffic` 'deep' 티어 | 배경(`cityBackdrop.js`)의 가운데 탑 층 뒤 → 가장 가까운 탑 층 앞, 지형보다 먼저 | 시트의 0.34배, 느림, 안개 0.4, 깜빡이는 운항등, 네온 하부광 |
| (배경 중간) | `SkylineTraffic` 'mid' 티어 | 모든 배경 탑 앞, 지형보다 먼저 | 0.6배, 일부 엔진 궤적 |
| Layer 2 중간 차선 | `LaneTraffic` 'drop' | **월드의 차선**(플라자와 언더시티 사이 낭떠러지, 맵 가장자리 세로 차선)을 소품·유닛과 함께 깊이 정렬 | 0.85배 |
| Layer 1 근경 | `LaneTraffic` 'over' | 언더시티 거리 위 높이 지나는 차선, 모든 것 위에(예전 빛줄기 자리) · 거리 바닥에 불빛이 쓸고 지나감 | 1.05배, 대부분 핑크/파랑 엔진 궤적 |

깊이 정렬에 대해: 요청은 "교통은 항상 맵 타일·소품 뒤"였지만, 이 맵의 낭떠러지 차선은 두 층 사이를 지나서 항상 뒤에 그리면
플라자 타일과 절벽 외벽에 거의 다 가려진다. 그래서 차선 교통은 소품·유닛과 같은 깊이 목록(x + y)에 넣어, 뒤의 플랫폼과 외벽
앞으로, 앞에 선 것 뒤로 지나가게 했다. 먼 배경 교통은 요청대로 맵 뒤에만 그린다.

## 움직임

- **경로**: 배경 교통은 등각 대각선(기울기 0.15~0.45, 0.5가 정확한 등각선)을 따라 화면을 가로지르는 3차 베지에 곡선이며,
  두 제어점을 서로 반대로 휘어 부드러운 S자로 굽는다. 차선 교통은 차선을 따라가며 좌우로 조금씩 흔들린다.
- **방향**: 시트의 차량은 모두 왼쪽 아래(SW)를 보고 있어서, 오른쪽 아래로 가는 차선은 좌우 반전해 쓴다. 뒷모습 그림이 없으므로
  화면 위쪽(멀어지는 쪽)으로 가는 차선은 카메라 쪽으로 오도록 방향을 뒤집었다(아니면 후진하는 것처럼 보인다).
- **속도**: 차급마다 다르다(레이서·스우프 > 고급 세단 > 통근 차 > 화물). 차마다 ±12% 차이가 있고, 천천히 빨라졌다 느려진다.
  차선에서는 앞차가 더 느리면 따라 속도를 줄인다(서로 겹쳐 지나가지 않음).
- **호버**: 리펄서로 뜬 듯 위아래로 살짝 흔들린다.

## 풀링과 스폰

- 배경은 티어마다 고정 풀(deep 30, mid 14), 차선은 전체 80대짜리 풀 하나. 화면(또는 차선) 밖으로 나가면 풀로 돌아간다.
- 스폰 간격은 지수분포(포아송)로 뽑아 박자가 생기지 않는다. 배경은 같은 방향 2.5초 안에 14px 안쪽 차선을 다시 쓰지 않고,
  차선은 직전 차가 입구를 비우기 전에는 넣지 않는다. 레벨을 열 때는 이미 흐르고 있도록 경로 중간에 미리 채운다.
- 언더시티(스모그)는 배경 교통 밀도가 0.7배.

## 빛 · 궤적

- `ENGINE_GLOW_PINK` / `ENGINE_GLOW_BLUE`: 시트의 분홍·파랑 줄기를 차의 뒤쪽 점(아틀라스의 `rear`)에 머리를 맞춰
  가산 합성으로 붙이고, 뜨거운 코어 빛을 더한다. 줄기 밝기는 엔진처럼 깜빡인다.
- 운항등: 뒤쪽 빨강 깜빡임, 앞쪽 흰 점. 먼 티어는 바닥에 네온 하부광(플라자는 따뜻한 색, 언더시티는 네온).
- 안개: 깊이마다 배경의 안개 색으로 미리 물들인 아틀라스를 쓴다(부드럽게 미리 축소, 프레임마다 다시 칠하지 않음).

## 설정 방법 (엔진 설정 대응)

| Unity라면 | 여기서는 |
|---|---|
| Sorting Layer / Order | 그리는 순서: `cityBackdrop.js`의 탑 층 루프 안(`TIERS[i].after`), `renderer.js`의 깊이 정렬 목록(`put(…, car)`), 마지막 `drawTraffic` |
| 프리팹 · 스프라이트 풀 | `public/sprites/traffic/traffic.png` + `traffic.json`(차량마다 위치·크기·차급·`rear`/`nose`) ← `python3 tools/sprites/traffic/extract.py`(`--contact out.png`로 조각 번호표) |
| 차급 분류 | `extract.py`의 `CLASS`(조각 번호 → swoop / cruiser / commuter / cargo) |
| 레이어 파라미터 | `skylineTraffic.js`의 `TIERS`(시차 `f`, 크기 `scale`, 안개, 풀 크기 `max`, 스폰 `rate`, 높이 `band`, 속도 `pace`, 궤적·운항등·하부광) |
| 차급 속도 | `CLASSES`(배경), `LaneTraffic.spawn`의 차급 배수(차선) |
| 차선 경로 | `src/world/worldgen.js`의 `this.traffic`(x0, y0 → x1, y1, 높이 z, 속도, 평균 간격, `over`) |

## 확인

`lift`, `west_alley`)에서 머리 위 차선이 보인다.
