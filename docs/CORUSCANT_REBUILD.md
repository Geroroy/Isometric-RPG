# 코러산트 재건 — 아트 디렉션 · 레벨 디자인

새 건물 시트 3장(상점·칸티나 16, 공동주택 탑 16, 공장·설비 16 = 48채)으로 코러산트(상층 플라자 + 언더시티)를 새로 짓는다.
**테스트 빌드에서만 켜고**(`?map=v2`, 테스트 빌드는 `VITE_MAP_V2=1`), 승인 뒤 기본으로 바꾼다.

## 1. 아트 디렉션

### 스케일 — 플레이어 기준 1:1 (ART_GUIDE.md)

1 m = 화면 위로 24.5 px, 타일 1칸 = 1 m(40 × 20 px), 사람 1.85 m ≈ 52 px. 시트마다 실측해 맞췄다(`tools/sprites/undercity_buildings/bake.py`):

| 시트 | 시트 위 1 m | 배율 | 결과 |
|---|---|---|---|
| 상점·칸티나 | ≈ 24 px (바 의자 0.75 m ≈ 18 px, 층 70~90 px) | 1.0 | 2~3층, 9~11 m, 바닥 5~10 × 5~10칸 |
| 공동주택 탑 | ≈ 13 px (발코니 한 층 ≈ 40 px = 3 m) | **1.5** (실측 1.85) | 층 ≈ 60 px(2.45 m, 사람 키 정도), 6층 안팎 |
| 공장·설비 | ≈ 12.5 px (셔터 ≈ 45 px = 3.5 m) | **1.4** (실측 1.9) | 셔터 ≈ 63 px(사람보다 한 뼘 높음) |

- **크기와 해상도의 타협.** 탑·공장은 시트가 작아(1 m ≈ 13 px) 실측대로 1.85~1.9배 키우면 ESRGAN을 거쳐도 캐릭터 옆에서
  눈에 띄게 뭉갰다. 1.5 / 1.4배로 줄였다: 한 층이 사람 키만큼, 셔터는 사람보다 조금 높게 남아 크기가 읽히고(1.35에선 층이 사람보다
  낮아 인형집처럼 보임), 확대가 줄어 선명하다. 상점은 시트가 이미 1:1이라 그대로.
- 업스케일(`upscale.py`): ESRGAN 4배 → **4배 단계에서 블러(반경 1.6)** → Lanczos로 1.5배 → 언샤프 90%. 시트가 블록 진 그림이라
  ESRGAN이 블록 경계마다 선을 그어 4 px 격자가 생기는데, 1.5배로 줄이면 이 격자가 화면 픽셀과 맞물려 그물 무늬가 된다 — 그 주기에서
  미리 흐려 없애고 줄인 뒤 다시 날을 세운다. 4배 결과는 `assets/city/buildings/x4/`에 캐시(깃 제외): 배율만 바꾸면 다시 돌리지 않는다.
- 시트의 등각 각도는 게임 타일(2:1)과 거의 같다 — 바닥 가장자리로 확인, 보정 없이 쓴다.

### 빛

- 건물은 시트에 이미 밤 조명이 그려져 있다(창문 주황, 네온 분홍·청록·보라). 게임의 밤 조명 패스가 이것까지 어둡게 하지 않도록,
  **빛나는 부분(간판·램프·창문)을 따로 떼어 `neon` 층**으로 조명 뒤에 다시 그린다(깜빡임은 약하게).
- 건물마다 가장 큰 발광부 하나에 은은한 **거리 조명**(채도·밝기를 낮춘 그 색, 그 높이)을 넣어 바닥과 사람을 물들인다.
- 네온 층은 빛나는 부분의 사각형(`neonRect`)만 아틀라스에서 잘라 그린다 — 매 프레임 가산 합성하는 넓이를 줄인다.
- 팔레트: 녹슨 철·검은 강철 + 주황 창문 + 네온 3색. 상층은 같은 건물이지만 더 밝은 하늘빛(기존 상층 조명 유지)으로 대비.

## 2. 레벨 디자인

### 원칙

1. **높은 것은 뒤로, 낮은 것은 앞으로.** 이 카메라에서 화면 위쪽(월드 x·y가 작은 쪽 = 북쪽 띠와 서쪽 띠)이 "뒤", 화면 아래쪽
   (동쪽·남쪽 띠)이 "앞"이다. 17~23 m 탑·공장은 뒤 가장자리에 세워 거리를 가리지 않고 도시의 벽이 되게 하고, 앞 가장자리는 낮은
   상점·노점·난간으로 열어 둔다.
2. **보이는 바닥 = 걸을 수 있는 바닥 (아래 "가림 규칙").** 건물은 절대 반투명해지거나 구멍이 뚫리지 않고, 플레이어 잔상도 없다.
3. **한 구역 = 한 성격.** 도착(터보리프트) → 시장 거리 → 중앙 네온 광장 → 칸티나, 옆으로 주거 스택과 공장 지대.
4. **시선 유도.** 리프트에서 내리면 시장 거리 끝에 광장의 빛(천장 틈으로 떨어지는 빛줄기)이 보이고, 광장 동쪽에 칸티나의 간판.
5. **길은 넓게, 골목은 좁게.** 큰길 6칸, 골목 3~4칸 — 큰 건물 사이로 사람(군중·경비 순찰)이 지나갈 폭.
6. 같은 건물이 이웃하지 않게(48채 중 골라 씀), 큰 건물 사이에는 기존 작은 소품(노점·자판기·가로등·상자)을 그대로 섞어 사람 크기의 디테일을 준다.

### 언더시티 (x 40~156, y 94~156 — 기존보다 넓다: 1:1 건물이 크기 때문)

```
        서(화면 왼쪽 위)                               북(화면 오른쪽 위)
  y 94 ┌──────────── 주거 탑 ─────────┬ 리프트 광장 ┬──────── 공장 지대(공장 3채) ────────┐
       │                              │  (82,98)    │                                      │
  y109 ├── 큰길(시장 거리) ─────────────────────────────────────────────────────────────────┤
       │ 주거  │ 상점 블록 │  중앙 네온 광장  │ 칸티나 │ 상점 블록 │ 정비소·공장 정문      │
       │ 스택  │           │  (98,126) 노점들  │(118,124)│           │                      │
       │ (탑)  ├── 골목 ───┤  빛줄기           ├────────┴── 골목 ──────────────────────────┤
       │       │ 상점 블록 │                    │ 상점 블록 │                               │
  y143 ├───────┴── 남쪽 산책로(난간·노점·전망대) ──────────────────────────────────────────┤
  y156 └ 낭떠러지 ─────────────────────────────────────────────────────────── 동쪽 끝: 시장 텐트 ┘
```

- **리프트 광장**(82, 98): 도착 지점. 탑 사이로 열린 작은 광장, 시장 거리로 이어진다.
- **시장 거리**(큰길, y 109~115): 동서로 관통. 북쪽은 탑·공장의 발치, 남쪽은 상점 정면.
- **중앙 네온 광장**(98, 126): 모자이크 바닥, 기존 노점·거래 터미널, 천장 틈의 빛줄기. 랜드마크 = 네온 클럽(보라).
- **칸티나 "녹슨 등불"**(118, 124): 둥근 칸티나 건물, 광장 쪽으로 문. 피그린 단은 그 앞.
- **주거 스택**(서쪽 띠): 탑들과 좁은 골목, 집 문 앞(주민 귀가 지점).
- **공장 지대**(북동): 공장 3채, 정문 앞이 노동자 출근 지점. 증기·소음.
- **남쪽 산책로·전망대**: 낮은 노점과 난간, 낭떠러지 너머 도시가 보이는 곳(풍경 감상용 축소와 짝).

### 상층 플라자 (x 62~124, y 38~79)

- 제다이 착륙장(117, 62)과 NPC(오비완·렉스·아소카·병참장교·R2), 터보리프트(82, 77.5)는 그대로.
- 북쪽 띠(y 38~49, 뒤)에 공동주택 탑을 세워 스카이라인을 만들고, 서쪽 띠(x 62~72)에 상점 몇 채. 동쪽·남쪽(앞, 낭떠러지)은 열어
  착륙장과 도시 전망을 살린다.

## 3. 지켜야 할 게임 고리

NPC 위치(npc.js `hub`), 착륙장·스폰·이륙, 터보리프트 두 곳, 칸티나 위치(`CITY.bar`/`barDoor`, 피그린), 빛줄기(`CITY.shaft`), 군중의
장소·순찰·귀가 지점(cityLife.json `places`, `patrols`), 노점의 상인 자리(`SHEET_PROPS.vendor`), 증기, 지역 이름(POI), 카메라 영역,
`walk.up/low`, 레벨 구분(y 90), QA 지점(smoke.mjs 등). v2에서는 이것들을 새 배치에 맞춰 다시 정한다(`src/data/undercity_v2.json`).

## 4. 만드는 방법

- `tools/sprites/undercity_buildings/extract.py` → `bake.py` → `public/sprites/undercity/`(48채, 1:1).
- `tools/maps/undercity_v2.py`: 배치 스크립트 — 구역별로 건물을 실제 바닥 크기로 놓고, 겹침·경계·통행(리프트에서 모든 지점까지
  길이 이어지는지)을 검사하고, 조명·장소·순찰을 만들어 `src/data/undercity_v2.json`을 쓴다. 지도 미리보기 PNG도 뽑는다.
- 게임: `?map=v2`일 때 이 데이터로 코러산트를 생성(worldgen), 새 스프라이트를 불러온다(citySprites). 기본 맵은 그대로.
- QA: 스모크 테스트(v2 지점), 걸어 다니며 여러 프레임 캡처(가림·정렬·충돌), 클릭 이동, 군중·순찰이 막히지 않는지, 프레임 시간.

## 5. 성능 (프레임 드랍)

SwiftShader에서 GPU 프로세스의 프레임당 CPU 시간(= GPU 일, `tools/qa/gpuspots.mjs`)과 프레임 콜백 길이(`tools/qa/hitches.mjs`)로 쟀다.

| 고친 것 | 내용 |
|---|---|
| 배경은 낭떠러지가 보이는 곳만 | `renderer.voidRect`: 16 px 격자로 화면 중 빈 타일(또는 맵 밖)이 보이는 사각형을 구해 하늘·건물 층·교통을 그 안에만 그린다(클립). 낭떠러지가 안 보이면 배경을 아예 안 그린다 |
| 조명 패스 | 빛마다 매 프레임 그라디언트를 만들던 것을 색별로 한 번 그린 64 px 원형 스프라이트로(세기는 globalAlpha) |
| 빈 발광 층 | 언더월드 소품 35개의 네온·반사 층은 전부 비어 있었는데 매 프레임 가산 합성으로 그렸다 → 불러올 때 비었으면 버림. v2 건물 네온은 빛나는 부분 사각형(`neonRect`)만 |
| 하늘 교통 | 기체마다 합성 모드를 두 번 바꾸던 것을 층마다 두 번으로(몸체 먼저, 헤드라이트는 한 번에), 차선 계산은 캐시 |
| 지형 미리 굽기 | 터보리프트 근처에선 반대편 도착 화면을, 평소엔 한 단계 축소한 화면을 프레임당 4 ms씩 미리 굽는다(`Terrain.warm`) — 리프트·축소 때 한 프레임에 300 ms 넘게 굽던 것이 없어짐 |
| 리프트 왕복 버그 | 도착 지점이 반대 리프트 발판에서 0.2칸이라 가만히 서 있으면 1.2초 뒤 되돌아갔다 → 발판에서 한 번 벗어나야 다시 작동 |

| 프레임당 GPU-ms (640×360 / 1280×720) | 상층 | 광장 | 큰길 | 전망대 |
|---|---|---|---|---|
| v2 이전 | 313 / 843 | 296 / 766 | 281 / 714 | 243 / 676 |
| v2 이후 | 225 / 785 | 213 / 539 | 209 / 642 | 203 / 625 |
| (v1 기본 맵) | 344 / 849 | 348 / 875 | 315 / 902 | 297 / 850 |

걷기 최대 프레임 122 → 9~14 ms. 리프트 도착 프레임의 JS는 ~360 → ~100 ms(나머지는 첫 사용 텍스처 업로드 — 소프트웨어 GPU에서 과장됨).

## 6. 가림 규칙 — 보이는 곳은 걸을 수 있고, 걸을 수 없는 곳은 보이지 않는다

피드백: "통과할 수 있게 생겼는데 못 지나가는 건물 사이 틈", "플레이어와 건물 레이어가 섞여 반투명하게 보임", "가까이 가면 소품이
커졌다 작아짐", "움직일 때마다 배경이 달라지고 스프라이트가 잘림". 원인과 처리:

| 증상 | 원인 | 처리 |
|---|---|---|
| 반투명하게 섞임 | 플레이어 잔상(28%)이 매 프레임 모든 것 위에 그려짐 + 가리는 건물에 둥근 구멍(컷아웃)·네온 50% | v2 맵(`world.occlusion = 'none'`)은 모든 층을 불투명하게 그린다 — 잔상·페이드·구멍 없음. 구멍(컷아웃)은 전부 삭제, 다른 맵은 원래의 디아블로식 페이드로 |
| 커졌다 작아짐 | 컷아웃이 소품의 배율 `k`(0.45~1.35)를 무시하고 원본 크기로 그림, 소품 사각형도 `k` 무시 | 컷아웃 삭제, `placeProp`의 사각형에 `k` 반영 |
| 배경이 달라지고 잘림 | 컷아웃 구멍으로 뒤 배경이 보였고, 배경을 그리는 사각형을 16 px 표본으로 찾아 얇은 낭떠러지 틈을 놓쳐 이전 프레임 픽셀이 남음 | 빈 타일의 마름모를 정확히 합친 사각형(`renderer.voidRect`), 프레임마다 먼저 한 번 칠함 |
| 지나갈 수 있어 보이는 틈 | 건물 뒤에 가려지는 타일을 닫으면서, 보이는 바닥까지 닫힘(건물 사이 틈의 입구, 막다른 주머니) | 아래 규칙으로 배치를 다시 짬 |

`tools/maps/undercity_v2.py`가 게임과 같은 그리기 순서(발자국 상자의 앞뒤, 상자가 겹치면 깊이 비교)와 같은 스프라이트 픽셀로 판정한다:

- **닫는 곳:** 발이 가려지는 타일(가운데, 또는 화면 좌우 두 점 모두 — 발 폭 3점 중 2점), 또는 건물이 몸의 60% 이상(폭 3열 × 높이
  4점)을 가리는 타일. 가로등·간판 같은 길거리 소품은 발을 가릴 때만 닫는다(그 앞을 지나며 잠깐 일부 가려지는 건 자연스러운 가림).
- **건물은 줄지어 붙여 세운다:** 같은 줄의 건물은 발자국 여유(0.4)만큼 겹쳐 벽이 맞닿는다 — 뒤로 이어지지만 들어갈 수 없는 틈이 없다.
  상점 두 줄(A·B)은 등을 맞댄 한 블록으로(그 사이 골목은 B줄 뒤에 완전히 가려져 보이지도 갈 수도 없었음).
- **가로등·증기 배출구는 큰길 북쪽 연석, 탑·공장 바로 앞:** 길 한가운데의 가로등은 간판이 뒤쪽 대각선 줄을 가려 큰길을 칸칸이 끊었다.
- **그래도 남는, 닫혔는데 바닥이 보이는 구석**은 잡동사니(상자·통·고철)로 채워 막힌 곳으로 보이게 한다.

| | 이전(v41) | 지금 |
|---|---|---|
