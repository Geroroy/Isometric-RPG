# 코러산트 재건 — 아트 디렉션 · 레벨 디자인

새 건물 시트 3장(상점·칸티나 16, 공동주택 탑 16, 공장·설비 16 = 48채)으로 코러산트(상층 플라자 + 언더시티)를 새로 짓는다.
**테스트 빌드에서만 켜고**(`?map=v2`, 테스트 빌드는 `VITE_MAP_V2=1`), 승인 뒤 기본으로 바꾼다.

## 1. 아트 디렉션

### 스케일 — 플레이어 기준 1:1 (ART_GUIDE.md)

1 m = 화면 위로 24.5 px, 타일 1칸 = 1 m(40 × 20 px), 사람 1.85 m ≈ 52 px. 시트마다 실측해 맞췄다(`tools/sprites/undercity_buildings/bake.py`):

| 시트 | 시트 위 1 m | 배율 | 결과 |
|---|---|---|---|
| 상점·칸티나 | ≈ 24 px (바 의자 0.75 m ≈ 18 px, 층 70~90 px) | 1.0 | 2~3층, 9~11 m, 바닥 5~10 × 5~10칸 |
| 공동주택 탑 | ≈ 13 px (발코니 한 층 ≈ 40 px = 3 m) | 1.85 | 6층 안팎, 17~20 m, 바닥 7~13 × 9~13칸 |
| 공장·설비 | ≈ 12.5 px (셔터 ≈ 45 px = 3.5 m) | 1.9 | 16~23 m, 바닥 9~19 × 10~19칸 |

- 줄이지 않는다. 탑·공장은 시트가 작아 1.9배 키운다 — 한 번, 오프라인에서(프리멀티플라이드 Lanczos + 약한 언샤프). 원본 해상도의 한계로
  캐릭터보다 살짝 부드럽다. 밤 장면이고 대부분 화면 위쪽(뒤)에 서므로 눈에 덜 띈다. (이 환경에서 AI 업스케일러 모델은 받을 수 없음.)
- 시트의 등각 각도는 게임 타일(2:1)과 거의 같다 — 바닥 가장자리로 확인, 보정 없이 쓴다.

### 빛

- 건물은 시트에 이미 밤 조명이 그려져 있다(창문 주황, 네온 분홍·청록·보라). 게임의 밤 조명 패스가 이것까지 어둡게 하지 않도록,
  **빛나는 부분(간판·램프·창문)을 따로 떼어 `neon` 층**으로 조명 뒤에 다시 그린다(깜빡임은 약하게).
- 건물마다 가장 큰 발광부 3곳까지 **거리 조명**(그 색, 그 높이)을 넣어 바닥과 사람을 물들인다 — 네온 거리의 색이 바닥에 떨어지게.
- 팔레트: 녹슨 철·검은 강철 + 주황 창문 + 네온 3색. 상층은 같은 건물이지만 더 밝은 하늘빛(기존 상층 조명 유지)으로 대비.

## 2. 레벨 디자인

### 원칙

1. **높은 것은 뒤로, 낮은 것은 앞으로.** 이 카메라에서 화면 위쪽(월드 x·y가 작은 쪽 = 북쪽 띠와 서쪽 띠)이 "뒤", 화면 아래쪽
   (동쪽·남쪽 띠)이 "앞"이다. 17~23 m 탑·공장은 뒤 가장자리에 세워 거리를 가리지 않고 도시의 벽이 되게 하고, 앞 가장자리는 낮은
   상점·노점·난간으로 열어 둔다. 앞에 꼭 서야 하는 건물은 플레이어를 가리면 반투명해진다(기존 렌더러).
2. **한 구역 = 한 성격.** 도착(터보리프트) → 시장 거리 → 중앙 네온 광장 → 칸티나, 옆으로 주거 스택과 공장 지대.
3. **시선 유도.** 리프트에서 내리면 시장 거리 끝에 광장의 빛(천장 틈으로 떨어지는 빛줄기)이 보이고, 광장 동쪽에 칸티나의 간판.
4. **길은 넓게, 골목은 좁게.** 큰길 6칸, 골목 3~4칸 — 큰 건물 사이로 사람(군중·경비 순찰)이 지나갈 폭.
5. 같은 건물이 이웃하지 않게(48채 중 골라 씀), 큰 건물 사이에는 기존 작은 소품(노점·자판기·가로등·상자)을 그대로 섞어 사람 크기의 디테일을 준다.

### 언더시티 (x 40~156, y 94~156 — 기존보다 넓다: 1:1 건물이 크기 때문)

```
        서(화면 왼쪽 위)                               북(화면 오른쪽 위)
  y 94 ┌──────────── 주거 탑 ─────────┬ 리프트 광장 ┬──────── 공장 지대(공장 3채) ────────┐
       │                              │  (82,98)    │                                      │
  y109 ├── 큰길(시장 거리) ─────────────────────────────────────────────────────────────────┤
       │ 주거  │ 상점 블록 │  중앙 네온 광장  │ 칸티나 │ 상점 블록 │ 정비소·공장 정문      │
       │ 스택  │           │  (98,126) 노점들  │(118,124)│           │                      │
       │ (탑)  ├── 골목 ───┤  빛줄기           ├────────┴── 골목 ──────────────────────────┤
       │       │ 상점 블록 │                    │ 상점 블록 │                               │
  y143 ├───────┴── 남쪽 산책로(난간·노점·전망대) ──────────────────────────────────────────┤
  y156 └ 낭떠러지 ─────────────────────────────────────────────────────────── 동쪽 끝: 시장 텐트 ┘
```

- **리프트 광장**(82, 98): 도착 지점. 탑 사이로 열린 작은 광장, 시장 거리로 이어진다.
- **시장 거리**(큰길, y 109~115): 동서로 관통. 북쪽은 탑·공장의 발치, 남쪽은 상점 정면.
- **중앙 네온 광장**(98, 126): 모자이크 바닥, 기존 노점·거래 터미널, 천장 틈의 빛줄기. 랜드마크 = 네온 클럽(보라).
- **칸티나 "녹슨 등불"**(118, 124): 둥근 칸티나 건물, 광장 쪽으로 문. 피그린 단은 그 앞.
- **주거 스택**(서쪽 띠): 탑들과 좁은 골목, 집 문 앞(주민 귀가 지점).
- **공장 지대**(북동): 공장 3채, 정문 앞이 노동자 출근 지점. 증기·소음.
- **남쪽 산책로·전망대**: 낮은 노점과 난간, 낭떠러지 너머 도시가 보이는 곳(풍경 감상용 축소와 짝).

### 상층 플라자 (x 62~124, y 38~79)

- 제다이 착륙장(117, 62)과 NPC(오비완·렉스·아소카·병참장교·R2), 터보리프트(82, 77.5)는 그대로.
- 북쪽 띠(y 38~49, 뒤)에 공동주택 탑을 세워 스카이라인을 만들고, 서쪽 띠(x 62~72)에 상점 몇 채. 동쪽·남쪽(앞, 낭떠러지)은 열어
  착륙장과 도시 전망을 살린다.

## 3. 지켜야 할 게임 고리

NPC 위치(npc.js `hub`), 착륙장·스폰·이륙, 터보리프트 두 곳, 칸티나 위치(`CITY.bar`/`barDoor`, 피그린), 빛줄기(`CITY.shaft`), 군중의
장소·순찰·귀가 지점(cityLife.json `places`, `patrols`), 노점의 상인 자리(`SHEET_PROPS.vendor`), 증기, 지역 이름(POI), 카메라 영역,
`walk.up/low`, 레벨 구분(y 90), QA 지점(smoke.mjs 등). v2에서는 이것들을 새 배치에 맞춰 다시 정한다(`src/data/undercity_v2.json`).

## 4. 만드는 방법

- `tools/sprites/undercity_buildings/extract.py` → `bake.py` → `public/sprites/undercity/`(48채, 1:1).
- `tools/maps/undercity_v2.py`: 배치 스크립트 — 구역별로 건물을 실제 바닥 크기로 놓고, 겹침·경계·통행(리프트에서 모든 지점까지
  길이 이어지는지)을 검사하고, 조명·장소·순찰을 만들어 `src/data/undercity_v2.json`을 쓴다. 지도 미리보기 PNG도 뽑는다.
- 게임: `?map=v2`일 때 이 데이터로 코러산트를 생성(worldgen), 새 스프라이트를 불러온다(citySprites). 기본 맵은 그대로.
- QA: 스모크 테스트(v2 지점), 걸어 다니며 여러 프레임 캡처(가림·정렬·충돌), 클릭 이동, 군중·순찰이 막히지 않는지, 프레임 시간.
