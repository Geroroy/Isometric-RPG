# 광선검 표현: 잔상 스타일 2가지 × 색상 2가지

레퍼런스(`reference/`, 커밋 안 함)에서 직접 측정한 값. 측정 도구: `tools/qa/saberprofile.py`(코어·링별 색과 밝기),
프레임 추출은 ffmpeg(12 fps 개요 + 원본 24/30 fps 구간). 구현: `src/gfx/saberStyle.js`.
비교 캡처: `tools/qa/saberlab.mjs` → `tools/qa/sabergrid.py`.

## 두 잔상 스타일

| 항목 | 클론워즈 | 영화 (시스의 복수) |
|---|---|---|
| 잔상 길이 | 휘두른 궤적의 마지막 **2~3프레임**(24 fps)이 한 덩어리로 남음 | **그 프레임 안에서만**(셔터 동안의 모션 블러). 다음 프레임엔 없음 |
| 사라지는 방식 | 칼이 멈추면 꼬리가 칼날 쪽으로 **줄어들며** 2~3프레임에 사라짐 (투명해지지 않음) | 칼이 멈추는 순간 없음 |
| 모양 | 단색 면(흰 코어색)으로 꽉 찬 **초승달/낫 모양**, 칼끝 쪽이 넓음 | 칼날이 **넓게 번진 쐐기**(끝이 둥긂), 칼날 쪽이 가장 밝고 뒤로 흐려짐 |
| 가장자리 | **또렷함**: 흰 면 → 1~2 px 안에 진한 색 테두리 (`#3475e1`) | **부드러움**: 8 px까지 거의 흰 연한 색(`#a7bbf8`→`#5963dc`) |
| 코어/글로우 | 코어 굵기 7 px(1280 기준), 글로우 밝기가 테두리의 절반이 되는 거리 ≈ 6 px | 코어 13~29 px, 글로우 절반 거리 ≈ 10~24 px (훨씬 넓고 밝음) |
| 빛 번짐 | 적음: 주변을 살짝 물들이는 정도 (+52 at 8–16 px) | 많음: 칼 주변이 하얗게 번짐 (+170 at 8–16 px) |
| 깜빡임 | 거의 없음: 정지한 칼의 글로우 밝기 변화 ±8% | 측정상 ±9% — 칼이 조금씩 움직여서 생긴 차이와 구분이 안 됨. 따로 떨리는 빛은 확인 못 함 (구현은 ±6%로 아주 약하게) |
| 칼끼리 부딪힘 | 교차점에 **작고 또렷한 흰 별빛** + 작은 불꽃 입자 | 화면 큰 부분이 **흰~주황으로 번쩍**(2프레임), 빛줄기 |

사용자가 생각한 차이와 비교: 클론워즈 = 셀 셰이딩·또렷한 가장자리·단색 면처럼 휘어지는 잔상·번짐 적음 → **레퍼런스와 같음**.
영화 = 하얀 코어·부드럽게 번지는 글로우·모션 블러 → **같음**. "살짝 떨리는 빛"은 레퍼런스에서 따로 확인되지 않음(위 표).

## 게임에 옮긴 방식 (본 게임 적용 — 설정 → 광선검에서 잔상 스타일·색상·길이·글로우)

시스의 복수 파랑 코어는 사용자 지정값 `#fcdefe`(살짝 분홍빛)를 쓴다. 레퍼런스에서 잰 값은 `#fcfefe` — 되돌리려면 `saberStyle.js`의 `PALETTES.rots.blue.core`.

- **칼날**: ① 8–16 px 색(`halo`)의 3 px 선을 일반 블렌드로 깔고(밝은 바닥에서 묻히지 않는 테두리), ② 글로우 스프라이트 1장
  (1–2/2–4/4–8/8–16 px 색을 한 장에 구움: 클론워즈 = 계단식 4단 띠, 영화 = 부드러운 감쇠·더 넓음)을 칼 방향으로 늘려 `screen`
  블렌드로, ③ 테두리색 선과 코어색 선. `shadowBlur` 없음, 칼 하나에 이미지 1장.
- **잔상**: 스프라이트 프레임이 바뀔 때마다 칼 위치를 기록하고 손잡이 기준 회전으로 보간한 곡선 궤적(5구간).
  - 꼬리 쪽으로 갈수록 안쪽 경계가 칼끝으로 당겨져 **초승달처럼 가늘어지고**(두께 그라데이션),
    휘두름이 끝나면(마지막 동작 후 45 ms 유예 뒤) 두께·밝기가 같이 줄어든다(시작→중간→끝 감쇠).
  - 클론워즈: 0.11초, 단단한 셀 레이어 — 어두운 테두리선 → 테두리색 초승달 → 그 안의 흰 초승달(경계 또렷).
  - 영화: 0.07초, 일반 블렌드 엷은 색(밝은 바닥용) → `screen`으로 넓은 부드러운 테두리 → 뒤에서 앞으로 밝아지는
    색 → 흰 그라데이션. 칼이 멈추면 바로 흐려진다.
- **칼 부딪힘**: 클론워즈 = 어두운 테두리가 있는 흰 불꽃 9줄 + 흰 별(가산), 영화 = 큰 블룸(`screen`: 밝은 바닥을
  하얗게 날려버리지 않음) + 작은 뜨거운 중심(가산) + 주황 불꽃 줄.
- **비용**(소프트웨어 GPU, 칼 그리기만): 지금 게임 1.0 ms → 새 표현 1.1–1.4 ms. 잔상을 그리는 경로·선 수를 줄여
  처음 프로토타입(2.3–2.9 ms)의 절반 이하.

## 광선검 빛 (캐릭터·맵에 비침) — `src/gfx/saberLight.js`

하나의 감쇠 모델을 라이트맵·지면·캐릭터·노멀 조명(`relight.js`)이 모두 쓴다.

- **감쇠**: 부드러운 역제곱 `1 / (1 + (d/r0)²)` + 칼날 근처 0~15 px의 뜨거운 코어 `0.7·e^-(d/9.5)²`(가산으로 1 이상까지 치솟음),
  reach 끝에서 0으로. 프리셋마다 256 px 스프라이트로 구워 빛 하나 = drawImage 한 번.
- **색조**: 표면에 맺히는 색은 칼 색과 다르다 — 파랑 `#00D2FF`(가까이) → `#1A75FF`(멀리), 빨강 `#FF5500` → `#FF2A00`.
  다른 색 칼은 테두리색에서 만든다. 코어 쪽은 near, 바깥은 far.
- **캐릭터**(노멀 없는 시트): ① 몸 = 자기 색 × far 틴트를 칼에서의 감쇠로 마스크해 **가산**(`lighter`) — 밤에는 원래 색을 뚫고 비침.
  ② **림 라이트** = near 틴트의 실루엣에서 칼 반대쪽으로 `rim` px 민 실루엣을 빼 **칼을 향한 외곽선**만 남김, 같은 감쇠로 마스크.
  노멀 시트(드로이드·클론)는 `relight.js`에서 같은 감쇠·틴트에 림 항 `(1 − n·z)²`을 곱해 실루엣이 밝아진다.
- **지면**: 2:1로 눌린 타원 스프라이트. 라이트맵(곱)에 약하게 + 그림 위에 가산/스크린으로 한 번 더(어두운 바닥에서 빛이 뚫고 나옴).
  휘두르면 `sweepOf()`가 잔상 기록에서 칼끝 경로의 방향·길이를 읽어 타원을 그 방향으로 늘리고 밝힌 뒤 잔상 길이만큼 감쇠.
- **프리셋**: 클론워즈 = r0 14 px, reach 4 r0, **4단 오파시티 밴딩**(가장 옅은 단은 0으로), 2 px 샤프 림, 지면 `lighter`.
  영화 = r0 18 px, reach 5.5 r0, 부드러운 감쇠, 1.5 px 림을 한 번 더 번지게, 지면 `screen`(디퓨전).
- 비용: 같은 전투 장면 12 fps 고정 측정에서 프레임당 GPU 합성 225 → 226 ms(변화 없음). 캐릭터는 칼마다 최대 4명.
