# CLONE WARS: 선택받은 자 — 게임 디자인 문서

> 스타워즈: 클론 전쟁을 배경으로 한 아이소메트릭 핵 앤 슬래시 ARPG.
> 디아블로 2의 조작감과 성장 구조에, 스타크래프트 1의 콘솔/초상화 UI를 결합한 올드스쿨 프로젝트.

## 2. 아트 디렉션

### 2.1 사전 렌더링 스프라이트 파이프라인
90년대 블리자드/웨스트우드 게임은 3D 모델을 미리 렌더링해 스프라이트로 썼습니다. 이 프로젝트는 같은 방식을 **브라우저 로딩 시점**에 재현합니다.

1. Three.js로 로우폴리·플랫 셰이딩 모델을 만든다 (`src/gfx/models/*`).
2. 직교 카메라(고각 30°, 방위 45°)로 각 방향 × 각 애니메이션 프레임을 렌더링한다.
   - 아나킨: **16방향**, 그 외 유닛: 8방향
3. 프레임마다 자르기(trim) → 4×4 Bayer 디더링 + 포스터라이즈(팔레트 축소) → 1px 어두운 외곽선.
4. 아틀라스 페이지(2048²)에 셸프 패킹.
5. 광선검 날의 시작/끝 같은 **마커 좌표**를 프레임별로 기록해, 런타임에 가산 합성 글로우와 궤적을 그린다.

### 2.2 화면 구성
- 게임 화면은 저해상도 캔버스(화면 높이 ÷ 약 460, 2~4배)를 최근접 보간으로 확대 → 굵은 픽셀감.
- 지형은 16×16 타일 청크 단위로 **픽셀마다** 생성: 바이옴 색 보간, 자갈/균열, 포장 석판, 도로, 크레이터 데칼, 디더링.
- 조명: 디아블로식 라이트맵(앰비언트 + 플레이어 광원 + 수정/램프/볼트/폭발 광원)을 곱하기 합성.
- 가산 합성 패스: 광선검, 볼트, 포스 파동, 번개, 폭발 불꽃.
- 건물 뒤에 플레이어가 가려지면 건물을 반투명 처리 + 실루엣 표시 (D2 방식).

### 2.3 아나킨 모델 (참고 이미지 기반)
| 부위 | 디자인 |
| --- | --- |
| 흉갑 | 건메탈 그레이 가슴판 + 등판, 높은 칼라 |
| 왼쪽 어깨 | 그레이 폴드런 + 붉은 공화국 문장 |
| 상의 | 짙은 남색 태버드(앞 갈라짐, 무릎 길이)가 버건디 튜닉 위로 |
| 팔 | 버건디 소매 + 갈색 긴 가죽 건틀릿 |
| 하의 | 버건디 바지 + 스트랩이 감긴 갈색 롱부츠 |
| 벨트 | 갈색 가죽, 은색 버클, 파우치 |
| 머리 | 어깨까지 오는 웨이브 갈색 머리, 오른쪽 눈의 흉터 |
| 무기 | 은색 힐트의 푸른 광선검 |

### 2.4 스타크래프트식 초상화 (레퍼런스 구도 기반 픽셀 아트)
3D 렌더가 아니라, 레퍼런스 이미지의 **구도와 배경**을 따라 그린 2D 픽셀 아트 초상화입니다 (`src/gfx/portrait.js`).

| 요소 | 레퍼런스 | 초상화 구현 |
| --- | --- | --- |
| 구도 | 레퍼런스 2 (일러스트) | 3/4 측면, 화면 왼쪽을 응시. 오른손에 쥔 광선검 날이 손에서 오른쪽 위로 **대각선**으로 화면을 가른다. 왼팔(공화국 문장 폴드런)은 오른쪽으로 뻗음 |
| 배경 A | 레퍼런스 2 | 라벤더/보라 빛 함선 복도, 오른쪽의 둥근 모서리 출입구에서 새어 나오는 빛 |
| 배경 B | 레퍼런스 3 | 원근감 있게 늘어선 녹색 천장 조명, 어두운 녹색 격납고 (드로이드 공장·격전지에서 자동 전환) |
| 의상 | 레퍼런스 1 | 건메탈 흉갑과 칼라, 남색 태버드, 버건디 소매, 갈색 건틀릿 |
| 얼굴 | 레퍼런스 전체 | 웨이브진 갈색 머리(옆 가르마), 짙고 낮게 깔린 눈썹, 오른쪽 눈을 지나는 흉터, 굳게 다문 입 |

제작 방식:
1. 큰 형태(배경, 머리카락, 피부 음영, 갑옷)는 4배 해상도에서 벡터 경로로 칠한다.
2. 96×80으로 축소 → 4×4 Bayer 디더링 + 포스터라이즈 → 픽셀 아트화.
3. 눈·눈썹·흉터·입은 저해상도에서 **픽셀 단위로 직접 배치** (선명함 유지).
4. 광선검 날은 픽셀마다 거리 기반으로 조명 — 흰 코어, 푸른 글로우, 얼굴과 갑옷에 번지는 푸른 빛, 미세한 깜빡임.
5. CRT 스캔라인, 통신 노이즈. 스타크래프트처럼 약 15fps로 애니메이션.

애니메이션: 숨쉬기, 눈 깜빡임, 시선 이동, 대사 시 입 움직임, 피격/통신 시 스태틱, 사망 시 흑백.
**어둠 게이지**가 오르면 홍채가 시스의 노란색으로 변하고 눈가가 붉어지며 배경에 붉은 기운이 드리운다.
초상화를 클릭하면 아나킨이 말한다 (계속 클릭하면 짜증을 낸다 — SC 오마주).

## 3. 조작 (디아블로 2 방식)

| 입력 | 동작 |
| --- | --- |

## 4. 캐릭터 성장

### 4.1 능력치 (레벨당 5포인트)
| 능력치 | 효과 |
| --- | --- |
| 힘 | 광선검 피해 +1.5% / pt |
| 민첩 | 공격 속도 +0.6%, 볼트 반사 확률 +0.3% / pt |
| 활력 | 생명력 +4 / pt |
| 포스 친화 | 포스 +2, 포스 피해 +1.2% / pt |

### 4.2 자원
- **생명력**(빨간 구슬) / **포스**(파란 구슬) — 디아블로식 구슬.
- **어둠 게이지**(빛 ↔ 어둠): 어둠의 기술(포스 초크, 선택받은 자의 분노)을 쓰면 상승, 시간이 지나면 서서히 감소.
  - 어둠 1포인트당 모든 피해 +0.3% (최대 +30%)
  - 어둠 1포인트당 포스 재생 -0.4%
  - 60 이상: "어둠의 유혹" 상태, 초상화의 눈이 노랗게 변하고 아나킨이 스스로를 경계하는 대사를 한다.
  - *설계 의도: 아나킨의 이야기 그 자체 — 강해지는 지름길은 대가를 요구한다.* (차기 마일스톤: 어둠 100 도달 시 일시적 각성/패널티, 엔딩 분기)

### 4.3 스킬 포인트
레벨당 1포인트. 시작 시 1포인트. 스킬은 각 20레벨까지.
티어 해금 레벨: **1 / 6 / 12 / 18 / 24**

### 5.4 블래스터 볼트 반사 규칙
- 드로이드는 실제 투사체(볼트)를 쏜다. 볼트가 아나킨에 닿는 순간 **반사 판정**.
- 반사 확률 = 12% + 민첩×0.3% + 쉬엔 반사 보너스 (최대 85%). 쉬엔 방벽 중에는 100%.
- 반사 성공 시 "되돌리기" 판정에 성공하면 **원래 사수에게 정확히 조준**, 실패하면 무작위 방향.
- 반사된 볼트는 공화국 편이 되어 피해량이 증가하며 드로이드에게 명중할 수 있다.
- 세이버 투척 중(손에 검이 없음), 기절·초크 중에는 반사 불가.

## 9. 게임 모드 (예정)

타이틀 화면에서 모드를 고른다:

```
┌──────────────────────────── CLONE WARS: 선택받은 자 ────────────────────────────┐
│   [ 캠페인 · 오픈월드 ]      [ 스테이지 셀렉션 ]       [ 무비 듀얼 ]             │
│   크리스토프시스 외곽 탐험    영화 속 전투 재현 미션     영화 속 1:1 광선검 결투   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

세 모드는 같은 엔진(스프라이트 베이커, 렌더러, 유닛, 스킬, 콘솔 UI)을 공유하고, 모드별로 **스테이지 정의 데이터**(지형 레이아웃, 스폰 웨이브, 트리거, 목표, 대사)만 달라진다.

### 9.1 무비 듀얼 모드

영화 속 명장면 결투를 1:1(또는 2:1)로 재현하는 보스 러시형 모드. 오픈월드의 핵 앤 슬래시와 달리, **광선검 대 광선검** 전용 전투 규칙을 쓴다.

#### 듀얼 전투 규칙
| 요소 | 설명 |
| --- | --- |
| 평정(Composure) 게이지 | 생명력과 별개. 막기·흘리기에 성공하면 상대의 평정이 깎이고, 0이 되면 **자세 붕괴** → 큰 피해를 넣을 수 있는 틈 |
| 막기 / 완벽한 흘리기 | 우클릭 홀드 = 막기 (평정 소모). 상대 공격 직전에 누르면 **완벽한 흘리기** → 반격 기회 |
| 칼날 겨루기 (Saber Lock) | 서로 동시에 강공격하면 발생. 좌클릭 연타 / 타이밍 바 미니게임, 이기면 상대를 밀어내고 추가 피해 |
| 포스 겨루기 | 서로 포스 푸시를 쓰면 중간에서 충돌하는 파동 줄다리기 |
| 형식(Form) 전환 | 젬 소(공격형: 피해↑, 평정 소모↑) ↔ 쉬엔(방어형: 반격·흘리기 판정↑)을 실시간 전환 |
| 페이즈 & 연출 | 보스 체력 구간마다 영화 장면 이벤트 + 짧은 대사 (예: 포스 번개를 광선검으로 받아내기, 무기 잃고 두 자루 사용) |
| 평가 | 시간·받은 피해·완벽한 흘리기 수로 S/A/B/C 랭크, 랭크에 따라 다음 결투 / 코스튬 해금 |
| 초상화 | 콘솔 초상화가 **아나킨 ↔ 상대**로 번갈아 바뀌며 대사 주고받기 |

#### 결투 목록
| # | 결투 | 원작 | 장소 / 배경 | 연출 포인트 |
| --- | --- | --- | --- | --- |
| 1 | 아나킨 vs 두쿠 백작 | 에피소드 II | 지오노시스 격납고 (녹색 조명 — 레퍼런스 3) | 오비완의 광선검을 받아 **쌍검** 페이즈, 포스 번개 |
| 2 | 아나킨 vs 아사즈 벤트레스 | 클론 전쟁 극장판 | 테스 수도원 | 상대는 곡선 손잡이 붉은 쌍검, 좁은 발코니에서의 결투 |
| 3 | 아나킨 & 오비완 vs 두쿠 | 에피소드 III | 인비저블 핸드 함교 | 2:1 태그 결투 (AI 오비완), 오비완 기절 후 1:1, 마지막 선택 연출 |
| 4 | 아나킨 vs 오비완 | 에피소드 III | 무스타파 | 용암 위 플랫폼·이동하는 지형, 어둠 게이지 최대 상태로 강제 진행 |
| 보너스 | 아나킨 vs 오비완 (훈련) | — | 제다이 사원 훈련장 | 튜토리얼 겸 연습 모드 |

### 9.2 스테이지 셀렉션 — 영화 속 장면 재현

홀로테이블(은하 지도) 화면에서 스테이지를 고르는 미션 모드. 스타크래프트 캠페인 브리핑처럼 **좌우 초상화 + 대사**로 브리핑하고, 정해진 목표와 연출이 있는 맵에서 진행한다.

| # | 스테이지 | 원작 | 목표 / 재현 장면 | 핵심 기믹 |
| --- | --- | --- | --- | --- |
| 1 | 크리스토프시스 전투 | 클론 전쟁 극장판 | 포위망 돌파, 아소카 합류, 실드 발생기 파괴 | 수정 도시 폐허, 현재 오픈월드 지형 재활용 |
| 2 | 지오노시스 전투 | 에피소드 II | 투기장 탈출 → LAAT 착륙 → 드로이드 코어선 격추 | 클론 대군 등장 이벤트, 건쉽 탑승 구간 |
| 3 | 테스 수도원 구출 | 클론 전쟁 극장판 | AT-TE로 절벽 오르기, 자바의 아들 구출 | 수직 절벽 진행, 마지막에 벤트레스 결투로 연결 |
| 4 | 라이로스 해방 | 클론 전쟁 시즌 1 | 포위된 마을 구출, 포대 무력화 | 협곡 지형, 렉스·클론 분대 지휘 |
| 5 | 코러산트 상공 전투 | 에피소드 III | 인비저블 핸드 잠입, 의장 구출 | 함선 내부, 버즈 드로이드, 두쿠 결투로 연결 |
| 6 | 무스타파 | 에피소드 III | (어둠의 길) 분리주의 지도부 제거 | 어둠 게이지 고정, 엔딩 분기, 오비완 결투로 연결 |

- 스테이지를 깨면 다음 스테이지와 해당 **무비 듀얼**이 해금된다 (스테이지 3 → 듀얼 2, 스테이지 5 → 듀얼 3 …).
- 스테이지에서 얻은 레벨·스킬은 캠페인 캐릭터와 공유 (선택).
- 난이도: 파다완 / 기사 / 마스터.

### 9.3 구현 계획
1. **모드 선택 타이틀 화면** + 공통 게임 루프 분리 (`GameMode` 인터페이스: 월드 생성, 승리/패배 조건, HUD 구성).
2. **스테이지 정의 포맷**: 지형(절차/수작업 타일), 소품 배치, 스폰 웨이브, 트리거(영역 진입·타이머·처치 수), 목표, 대사 스크립트.
3. **듀얼 시스템**: 평정 게이지, 막기/흘리기 판정, 칼날 겨루기, 보스 AI(공격 패턴 테이블 + 페이즈), 듀얼 전용 HUD.
4. 신규 모델: 두쿠 백작(곡선 손잡이 붉은 광선검, 망토), 아사즈 벤트레스, 오비완 케노비, 아소카 타노 — 기존 리그/베이커 재사용.
5. 상대별 픽셀 초상화 (아나킨 초상화와 같은 파이프라인).
