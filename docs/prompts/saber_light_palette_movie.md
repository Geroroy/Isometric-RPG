# 광선검 반사광 색 — 영화와 같게 (프롬프트)

## v1 (초안)

광선검이 바닥·캐릭터에 비치는 색(`src/gfx/saberLight.js`의 `TINTS`)이 파랑보다 청록(cyan)에 가깝다. 영화(시스의 복수)
레퍼런스에서 반사광 색을 측정해 `TINTS`를 맞춰 줘.

## 자체 검토 → 고친 점

1. **"반사광"을 무엇으로 잴지 정의가 없다.** 칼날 바로 옆 픽셀은 표면에 맺힌 빛이 아니라 칼의 블룸(카메라 번짐)이다. 블룸과 반사를
   나눠 재야 한다 — 블룸은 어두운 배경(하늘·연기) 위, 반사는 질감 있는 표면(얼굴·팔·옷·금속·바위) 위.
2. **배경색이 섞인다.** 무스타파는 주황 용암빛이 강해, 표면 픽셀의 색을 그대로 재면 파랑+주황의 혼합(보라·회색)이 나온다.
   측정할 것은 픽셀 색이 아니라 **칼 빛이 더한 색** — 같은 표면의 칼에서 먼 쪽(기준)과 가까운 쪽의 차이 벡터의 색상이다.
3. **가까이/멀리 두 색이 필요하다.** 게임은 칼 가까이 `near`, 멀리 `far` 두 색을 감쇠로 섞는다. 거리 구간별로 재서 둘을 고른다.
   거리는 영상의 칼 길이로 정규화한다(칼 길이 ≈ 게임에서 1.0 m ≈ 40 px).
4. **빨강도 영화 기준이 필요하다.** 무스타파 영상은 파랑뿐. `motion/KT_MysticLight_Anakin_Signature_Move.mp4`에 빨간 칼이
   나오는 구간이 있으면 같은 방법으로, 없으면 파랑에서 잰 패턴(색상 이동·채도·명도 비)을 빨강 칼 색에 그대로 적용한다.
   초록·보라도 같은 패턴으로.
5. **"청록이 아님"을 수치로 확인한다.** 결과 색상(°)을 현재 값(near 191°, far 216°)과 표로 비교, 칼날 색상표
   (`PALETTES.tcw.blue` rim 218°)와 어울리는지.
6. **게임 안에서 본다.** 같은 장면을 바꾸기 전/후로 캡처해(어두운·밝은 바닥, 캐릭터 림) 레퍼런스 프레임과 나란히 비교하고,
   화면에서 칼 주변 바닥 픽셀의 색상 분포를 잰다. 문서(`docs/SABER_STYLE.md` 색조 줄)와 코드를 같이 고친다.

## v2 (실행)

`reference/trail_movie/KT_MysticLight_RotS_Mustafar_0024-0116.mp4`(시스의 복수 무스타파, 파란 칼)에서:
1. 프레임을 뽑아(초당 2장) 칼날 코어(매우 밝고 푸른 흰색, 가늘고 긴 덩어리)를 찾고, 코어로부터의 거리(칼 길이로 정규화) 구간별로
   주변 픽셀을 모은다.
2. 각 픽셀을 **블룸**(어둡고 매끈한 배경 위)과 **표면**(질감 있음: 국소 표준편차 큼)으로 나눈다.
3. 표면 픽셀은 같은 프레임에서 칼에서 먼 같은 밝기대의 표면을 기준으로 삼아 **칼 빛이 더한 색**(차이 벡터)의 색상·채도를 잰다.
   블룸은 픽셀 색 자체.
4. 가까운 구간(칼 길이의 0.1~0.3)과 먼 구간(0.3~0.8)의 중앙값으로 `near`·`far`를 정하고, 빨강·초록·보라는 같은 패턴으로.
5. `TINTS`와 `docs/SABER_STYLE.md`를 고치고, 게임 안에서 전/후·레퍼런스를 나란히 캡처해 색상 수치로 확인. 테스트 빌드 업로드.
