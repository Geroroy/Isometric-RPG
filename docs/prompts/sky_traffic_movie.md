# 코러산트 상공 에어스피더 — 영화처럼 (프롬프트)

isometric-rpg 리포에서 **코러산트 상공(플랫폼 바깥 배경)의 에어스피더 교통 노선과 움직임을 영화(「클론의 습격」 코러산트 야경,
`reference/motion/coruscant_skyline_traffic.gif`)와 똑같게** 만들어 줘. 스피더는 지금처럼 배경에서만 난다(플랫폼 위·옆 차선은 끈 채로).
기존 8방향 기체 스프라이트(`public/sprites/traffic`)를 쓰고, 실행 중 크기 변경·색 덧칠 없이 미리 만든 크기만 쓴다.

## 레퍼런스에서 읽은 것 (34프레임, 20 fps)

1. **층층이 쌓인 수평 차선.** 하늘에 같은 방향의 평행선이 여러 높이로 쌓여 있다. 한 묶음(스카이웨이)은 3~4차선, 차선 사이가 좁고
   **이웃 차선은 반대 방향**. 묶음과 묶음 사이는 넓게 비어 있다.
2. **경사 램프.** 화면 왼쪽에 기체들이 가파른 대각선으로 줄지어 오르내리는 흐름이 있다 — 높이가 다른 차선 사이를 잇는 진입로.
3. **깊이.** 같은 화면에 크기가 5배 넘게 차이 나는 기체가 섞인다. 멀수록 작고 느리고(화면상 속도), 아주 먼 것은 헤드라이트 점과
   가는 선뿐이다. 가까운 큰 기체는 드물게 빠르게 지나간다.
4. **움직임.** 차선 안에서는 같은 속도로 일정하게 흐른다(추월·지그재그 없음). 간격은 불규칙하지만 겹치지 않는다. 갑자기 나타나거나
   사라지지 않고 화면 밖에서 들어와 화면 밖으로 나간다.
5. **빛.** 기체마다 앞쪽에 밝은 청백색 헤드라이트 점(작은 번짐). 몸체는 어두운 실루엣에 가깝다. 밀도는 화면에 30~50대.

## 아이소메트릭으로 옮기기

- "수평" 차선 = 등각 축 방향(화면 2:1)으로 뻗은 직선. 쌓인 높이 = 화면 위쪽으로의 오프셋. 묶음마다 한 축(\ 또는 /), 깊이 층마다 축을
  번갈아 써서 층끼리는 엇갈려 지나간다(영화의 서로 다른 고도에서 교차하는 흐름).
- 램프 = 같은 축으로 가며 화면상 오르내리는 가파른 선(한 칸 갈 때 2~3 px 오르내림). 기체 방향은 수평 진행 방향의 뷰.
- 깊이 층(멀리→가까이): ① 점(헤드라이트+가는 선), ② 1/4 크기, ③ 1/2 크기, ④ 원래 크기(드묾). 층마다 패럴랙스·속도·밀도가 다르다.
  1/4 아틀라스는 오프라인에서 만든다(`tools/sprites/traffic/extract.py`).
- 결정적 흐름: 차선마다 긴 주기의 기체 배열(시드 고정 간격)을 일정 속도로 흘려, 시점(카메라 이동·확대 축소·층 이동)과 상관없이
  같은 하늘이 이어진다 — 생성·소멸 팝인이 원리적으로 없다.
- 그리는 순서: 건물 배경 층 사이(먼 랜드마크 뒤에 ①②, 도시 블록 뒤/앞에 ③, 가까운 공장 앞에 ④).

## 확인

- 같은 기체를 프레임마다 추적해 팝인 0, 역주행·지그재그 0, 방향과 스프라이트 뷰 불일치 0, 같은 차선 겹침 0.
- 화면에 보이는 대수(하늘 부분), 층별 크기·속도 표. 여러 프레임 캡처로 레퍼런스와 나란히 비교.
- 프레임 시간(배경 그리기만) 전/후.
