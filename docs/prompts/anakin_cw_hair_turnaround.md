# 아나킨 클론워즈 헤어 — 턴어라운드 그대로 재현하는 Claude Code 프롬프트

참고 이미지: `reference/color_clonewars/image_2.jpg` (1920×784, 클론워즈 CG 스타일 턴어라운드:
옆(왼쪽 프로필) · 정면 · 뒤 · 옆(오른쪽 프로필), 눈높이 정사영에 가까운 카메라, 회청색 배경).

## 이미지에서 읽은 헤어

| 항목 | 내용 |
|---|---|
| 스타일 | 조각한 듯한 큰 덩어리(클럼프) 12~20개. 가닥 질감은 없고, 덩어리마다 완만한 능선과 얕게 판 홈이 있음. 끝은 부드럽게 뾰족함. 무광, 평평한 셰이딩 |
| 실루엣 | 두피 위로 정수리 2~3 cm 부피, 관자놀이 높이에서 가장 넓음. 헬멧처럼 둥글지만 아래 끝단은 들쭉날쭉 |
| 앞 | 가운데에서 살짝 비낀 가르마. 앞머리가 커튼처럼 양쪽으로 갈라져 이마 가운데가 역V자로 보이고, 옆 가닥이 광대뼈~턱선까지 얼굴을 감쌈 |
| 옆 | 귀를 완전히 덮음. 턱선(귓불 바로 아래)까지 내려오고, 끝에서 2~3단 계단처럼 바깥·뒤로 뻗친 뾰족한 덩어리(단마다 2~3 cm) |
| 뒤 | 정수리 가마에서 아래로 흐르는 세로 물결 덩어리. 목 중간(칼라 바로 위)에서 끝나고, 끝단은 V자 뾰족 덩어리 6~8개. 몇 개는 바깥으로 살짝 뒤집힘 |
| 색 (JPEG에서 측정, ±10) | 그늘 `#3a261c` · 중간 `#5a3e2e` · 밝은 면 `#8a6146` (정수리 하이라이트는 `#9a6c48` 정도). 뿌리·안쪽 층은 어둡게, 위쪽 능선은 캐러멜빛으로 밝게 |

## 프롬프트 (그대로 Claude Code에 붙여 넣기)

```
reference/color_clonewars/image_2.jpg 턴어라운드(옆·정면·뒤·옆)의 아나킨 헤어를 최대한 똑같이 헤어 메시로
만들어 줘. 대상 외형은 cw_s1(tools/sprites/out/anakin_cw_s1.glb)이고, 결과는 게임용 프리렌더 아이소메트릭
스프라이트와 2048 px 아이소 단일 이미지다. CLAUDE.md와 ART_GUIDE.md 규칙을 따른다 (render_config.json, 렌더
전에 ESTIMATE, 30분 넘으면 묻기, --preview 먼저, 바뀐 것만 렌더, 패스는 한 번 렌더로).
헤어 설명과 측정 색은 docs/prompts/anakin_cw_hair_turnaround.md에 있다.

규칙
- 얼굴·몸·옷은 건드리지 말고 헤어 메시와 헤어 텍스처만 바꾼다. 원본 GLB는 덮어쓰지 않는다.
- 기존 헤어는 *_hair_backup.blend로 백업한 뒤 제거한다 (tools/sprites/hair/hair_v2.py 방식).
- 헤어는 'head' 뼈 웨이트 1 + 아마추어 모디파이어. 폴리곤은 기존 헤어의 1.5배 이내.
- 모양은 전부 파라미터 파일 tools/sprites/hair/hair_cw_turnaround_params.json에서 정한다.

1. 참고 시트 만들기
   - 턴어라운드에서 머리 4개(왼쪽 프로필, 정면, 뒤, 오른쪽 프로필)를 같은 배율로 잘라
     renders/cw_hair_ref/에 저장한다. 크기 기준: 턱끝~정수리 높이를 같게 맞춘다.
   - 이미지를 직접 보고 가르마 위치(정면 기준 어느 쪽인지), 옆 끝단 계단 수, 뒤 끝단 덩어리 수를 세어
     표로 기록한다. 이것이 목표 사양이다.

2. 헤어 메시 (tools/sprites/hair/hair_v2.py를 확장)
   - 가이드 곡선 → 덩어리(클럼프) 방식 유지. 필요한 기능을 추가한다:
     · 'part': 가르마 각도·위치, 양쪽 커튼 앞머리 그룹.
     · 'tiers': 옆머리 끝을 2~3단 계단으로 뻗치게 하는 그룹별 끝 길이·바깥 각도.
     · 'groove': 덩어리 단면에 얕은 홈(조각한 느낌) — 메시 단면 형상으로, 노멀맵은 약하게.
     · 뒤 끝단 V자 덩어리 6~8개, 그중 1~2개 바깥으로 뒤집기.
   - 재질: 무광(거칠기 0.6~0.75), 뿌리→끝 그라디언트(그늘 #3a261c → 중간 #5a3e2e), 덩어리 능선에
     밝은 면 #8a6146. 가닥 텍스처 없이 붓으로 칠한 듯한 부드러운 얼룩만.
   - 결과: tools/sprites/out/anakin_cw_s1_hairT.glb

3. 맞춰 보기 (renders/cw_hair_iter_N/, 최소 3회, 최대 8회)
   - tools/sprites/hair/hair_review.py에 턴어라운드와 같은 카메라(눈높이 정사영, 왼쪽·정면·뒤·오른쪽)를
     추가하고, 참고 시트와 같은 배율로 렌더한다.
   - 뷰마다 [참고 | 렌더 | 실루엣 겹침(참고=빨강, 렌더=청록, 겹침=흰색)] 비교 시트를 만들고,
     실루엣 IoU를 계산해 표로 남긴다. 목표: 네 뷰 모두 IoU ≥ 0.90.
   - 매 반복마다 바꾼 파라미터와 IoU 변화, 눈으로 본 차이(가르마·계단·끝단·부피)를 notes.md에 기록한다.
   - 게임 크기 확인도 같이: 128 px 아이소 3방향(정면 쪽·3/4·뒤)에서 얼굴이 가려지지 않는지,
     머리 실루엣이 옷과 구분되는지.

4. 프리렌더 아이소메트릭 이미지
   - tools/sprites/hair/iso_portrait.py로 renders/iso_portrait/anakin_cw_s1_hairT_iso_2048.png:
     정사영, 35.26° 내려다봄, 오른쪽 앞, 전신, 2048×2048 알파 16bit PNG, 부드러운 스튜디오 조명,
     idleOff에서 얼굴이 보이게 머리를 살짝 든다. 머리 클로즈업(1024)도 한 장.

5. 게임 적용은 검토 후
   - --preview로 확인 → ESTIMATE 보여 주기 → tools/sprites/out/review/에 전체 시트 렌더.
   - 비교 기준을 맞추기 위해 기존 헤어 시트도 같은 파이프라인으로 review_old/에 렌더한다.
   - tools/qa/lookshot.mjs + lookcompare.py로 이전/이후 비교 스크린샷을 올리고, 승인받은 뒤에만
     public/sprites/로 옮기고 render_config.json을 고쳐 커밋·푸시한다.

마지막 보고: 최종 이미지 경로, 파라미터 파일, 뷰별 IoU 표, 참고 이미지와 남은 차이를 표로.
```

## 참고

- 턴어라운드는 클론워즈 후반(시즌 5~7 쪽) 스타일이고 머리가 시즌 1보다 길다. cw_s1 외형에 쓰면 시즌 1 사진과는 머리 길이가
  다르다. 그대로 쓸지, 이 헤어로 별도 외형을 만들지는 프롬프트 첫 줄의 "대상 외형"만 바꾸면 된다.
- IoU 0.90은 정사영 실루엣 기준이다. 얼굴 크기·두상이 게임 모델과 달라서 그보다 높이기는 어려울 수 있다(두상은 건드리지 않으므로).
