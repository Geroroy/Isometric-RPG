# 결투 캐릭터 외형 — 부족한 모델·재질 요구사항 (아나킨 · 오비완, 《시스의 복수》 무스타파)

> 현재 스프라이트(`public/sprites/duel/hero_*`, 프리렌더 모델 v1)는 **승인 전의 검토용**이다. 아래 표의 "현재"는 지금 무엇으로
> 대신하고 있는지, "요구"는 그 부분을 최종 품질로 올리는 데 필요한 것이다. 받는 즉시 같은 파이프라인(`docs/CHARACTERS.md`)에 넣어
> 같은 리그·같은 동작·같은 마커로 다시 렌더한다 — 동작·판정·게임 코드는 바뀌지 않는다.
>
> 파이프라인 쪽 조건(모든 항목 공통): Blender로 열 수 있는 형식(.blend 우선, 아니면 .fbx/.glb + 텍스처), 미터 단위, 오른손 좌표 Z 위,
> 정면 +X 또는 −Y(어느 쪽인지 적기), T자 또는 A자 기본 자세. 캐릭터 몸은 MakeHuman 1.1 기본 골격(`tools/sprites/hero/mh.py`)에
> 맞추거나, 다른 골격이면 관절 이름·위치 표를 같이 준다. 렌더 크기에서 판단한다: 게임 1배에서 키 ≈ 45~57 px, 결투 시험장에서
> 게임 px의 2~4배(머리 ≈ 15~35 px) — 머리카락·얼굴의 큰 형태, 옷의 층과 실루엣이 미세 디테일보다 중요하다.

## 1. 얼굴 (가장 큰 부족분)

| | |
|---|---|
| 현재 | MakeHuman 기본 얼굴을 슬라이더로만 다듬은 **일반적인 얼굴**(배우를 닮게 만든 것이 아님), 1K 피부 텍스처 한 장(`young_lightskinned_male_diffuse.png`), 노멀·러프니스 맵 없음 |
| 요구 | 캐릭터마다 머리 스컬프트 1개(목 아래까지): 영화의 의상·분장에 맞는 나이·체형, 아나킨 오른쪽 눈 위 흉터. 실존 배우의 얼굴을 스캔·복제하지 않는 **양식화된 닮음**(실존 인물 초상권). 4~8천 사각면, UV 펼침, 2K 텍스처: 색·노멀·러프니스(피부결·수염 자리 그림자). MakeHuman 머리와 같은 목 둘레에 이어지게(이음매 위치 표시) |
| 확인 | `tools/sprites/hero/review.py` 머리 확대 + `compose_review.py` 게임 크기 |

## 2. 의상 (현재는 몸 표면을 들어 올린 껍데기)

| | |
|---|---|
| 현재 | `garments.py`가 몸 표면을 들어 올려 만든 튜닉·바지·속튜닉, 둘레를 돌려 만든 치마·오비·허리띠, 표면 위 띠로 만든 타바드, 절차적 주름(형상 + 범프). **천 시뮬레이션 없음**(뼈 가중치로만 따라감), 겹친 앞섶 가장자리·바느질선·두께 차이 없음 |
| 요구 (아나킨) | 거의 검은 짙은 갈색 울 튜닉(긴소매, 무릎 위 치마, 앞섶이 겹치는 V), 검은 속튜닉(세운 깃), 검은 가죽 타바드 2장(어깨 너머 앞·뒤, 허리띠 아래로 늘어짐), 검은 가죽 오비, 짙은 갈색 가죽 허리띠 + 버클 + 파우치·캡슐, 검은 바지, 무릎 아래 검은 가죽 부츠, 오른손 검은 가죽 장갑(손목 커프) |
| 요구 (오비완) | 귀리색 리넨 튜닉·치마, 크림색 속튜닉, 같은 계열 리넨 타바드, 밝은 오비, 갈색 가죽 허리띠 + 버클 + 파우치, 황갈색 바지, 갈색 가죽 부츠 (무스타파 결투에는 로브 없음) |
| 형식 | 옷마다 따로인 메시(층이 겹치는 순서대로), 기본 자세의 몸에 맞춘 상태, 2K 텍스처(색·노멀·러프니스: 울 직조·리넨·가죽 주름), 의상 주름을 메시에 조각(정지 주름). 가능하면 치마·타바드는 따로 표시(나중에 천 시뮬레이션 대상) |

## 3. 광선검 손잡이

| | |
|---|---|
| 현재 | 원통 몇 개로 만든 단순한 손잡이(`pose_hero.py hilt_parts`, 29 cm) |
| 요구 | 아나킨(《시스의 복수》의 두 번째 광선검)·오비완(같은 영화의 것) 손잡이 각 1개, 길이 28~30 cm, 축 = 날 방향(+Z), 원점 = 오른손이 쥐는 자리, 날이 나오는 끝 표시. 1~3천 면, 금속·고무 그립 재질 |

## 4. 머리카락·수염 (지금 쓸 만함 — 개선 여지만)

| | |
|---|---|
| 현재 | 아나킨: 기존 헤어 커브 생성기(`tools/sprites/build_hair.py`, 약 1만 가닥)를 새 머리에 맞춤. 오비완: `groom.py`가 MakeHuman 머리·수염 프록시 위에 짧은 가닥을 심음 |
| 요구 (선택) | 영화 기준의 그룸 파일(Blender 헤어 커브) — 아나킨: 어깨에 닿는 웨이브, 가르마 / 오비완: 짧게 뒤로 넘긴 머리, 짧게 다듬은 턱수염·콧수염 |

## 5. 움직임에 딸린 2차 동작 (모델이 아니라 렌더 방식)

현재 머리카락·옷자락은 몸을 그대로 따라간다(관성·흔들림 없음). 휘두를 때 치마·타바드가 늦게 따라오는 것을 원하면 동작마다 천
시뮬레이션을 구워야 한다 — 렌더 시간이 크게 늘어 별도 결정이 필요하다.

## 공통 가독성 조건 (`docs/ASSETS.md` §5)

캐릭터·광선검이 바닥과 배경 위에서 또렷해야 한다: 아나킨의 검은 복장은 테두리 빛(오른쪽 뒤 청백 림 라이트)과 가죽 광택으로 실루엣이
읽히게, 오비완의 밝은 복장은 바닥보다 밝게. 광선검과 비슷한 밝은 청색 선·발광을 옷에 넣지 않는다.

## 출처·라이선스 확인 (사용자 결정 필요)

몸·얼굴·피부·눈·눈썹·속눈썹·머리·수염 프록시는 npm 패키지 `makehuman-data@0.0.2`(MakeHuman 1.1 데이터의 three.js 변환본)에서
온다. 파일 머리말은 AGPL3(+ MakeHuman의 외부 도구 예외)이고, MakeHuman 측은 MakeHuman으로 만든 모델의 출력물을 자유롭게 쓸 수
있다고 밝힌다. 저장소에는 원본 데이터를 넣지 않고(빌드 때 내려받음, `tools/sprites/hero/fetch_makehuman.sh`) 렌더한 스프라이트만
넣었다. **공개 배포 전에 이 조건을 받아들일지 사용자가 확인한다.** 위 1·2를 외부 제작 모델로 바꾸면 이 의존은 몸·손에만 남는다.
