# 코러산트 언더시티 지도 (`src/data/undercity.json`)

캠페인 허브의 하층(언더시티)을 첨부된 컨셉 시트의 스프라이트만으로 새로 짰다. 상층 플라자(제다이 착륙장, NPC)는 그대로이고
터보리프트(x 82)로 내려온다. 생성은 `src/world/worldgen.js` `CityHub`가 이 JSON을 읽어서 한다 — 바닥 폴리곤, 소품 배치,
조명, 웅덩이, 증기, 지역 이름(`pois`), 랜드마크 좌표(`points`). 스프라이트는 `tools/sprites/underworld/extract.py`가
`reference/unsorted/coruscant_underworld_tileset_A/B.png`에서 잘라낸 `public/sprites/underworld/`(35종 + 바닥 텍스처 6종).

## 좌표계와 격자

- 아이소메트릭 2:1, 타일 56×28 px. 월드 타일 x는 화면 오른쪽 아래, y는 왼쪽 아래. 하층 영역 x 58–138, y 94–133.
- 바닥은 비옴으로 나누고(`ground`), 비옴마다 시트의 텍스처를 월드 좌표로 샘플링한다(`terrain.js` `setGroundTextures`,
  2×2 또는 3×3 타일마다 반복, 셀마다 변형 선택). 네온 모자이크(03·04)는 폐기해 광장도 그레이트·환기구 금속판을 쓴다.

| 비옴 | 텍스처 | 이동 |
|---|---|---|
| `CITY_LOW` 금속판 | METAL_PLATE_AUREBESH / GRATE / VENT (2타일 반복, 셀마다 변형) | 보통 |
| `CITY_MOSAIC` 광장 | METAL_PLATE_GRATE·VENT 위주 | 보통 |
| `CITY_MUD` 진흙 골목 | MUD_CONDUIT (3타일) | ×0.72 |
| `CITY_SWAMP` 하수 웅덩이 | UNDERWORLD_SWAMP_A | ×0.6 |
| `CITY_DIRT` 흙바닥 안뜰 | DIRT_TILES | 보통 |
| `VOID` 낭떠러지 | 어둠 + 아래 도시의 불빛(terrain.js) | 통행 불가 |

## 경계 (`boundaries`)

- **북쪽** y 94–99: 수직 파이프 스택 11개, 스팀 벤트 2, 아파트 모듈 7개가 빈틈없이 선다. 가장 바깥 타일 띠(x 58, x 137, y 94)는
  막혀 있어 낭떠러지 턱에 서지 못한다. 들어오는 길은 터보리프트(82, 97.5) 하나.
- **남쪽** y ≥ 133: 낭떠러지(VOID). 턱에는 스팀 벤트와 파이프 스택. 광장 남쪽으로 만(灣)이 y 126까지 파고들어 전망대가 된다.
- **서쪽** x 59–63: 아파트 모듈 벽, 골목 끝의 쓰레기 압축기(61.5, 116) + 버려진 스피더(63.8, 119.8).
- **동쪽** x 133–137: 아파트 모듈 벽 + 밀집 시장 건물(135, 115.5), 파이프 스택.
- 겹침: 소품은 깊이(x+y)로 유닛과 함께 정렬되므로 뒤에 서면 가판대 차양·파이프·가로등이 캐릭터를 가린다. 도관 다발은
  충돌 없는 바닥 소품(`flat`)이라 밟고 지난다. 증기 입자는 소품 위에 그려진다.

## 충돌

- 통행 불가: 모든 건물·가판대·파이프·압축기·스피더·고철·드럼통·상자(스프라이트 JSON의 `footprint` 다각형), 낭떠러지(VOID).
- 통행: 금속판, 광장, 진흙, 흙. 느려짐: 진흙 ×0.72, 하수 웅덩이 ×0.6(`Player.moveSpeed`).
