# CLONE WARS: 선택받은 자 (Isometric RPG)

스타워즈 **클론 전쟁**을 배경으로 한 올드스쿨 아이소메트릭 핵 앤 슬래시 RPG 프로토타입.
디아블로 2의 조작/성장 구조에, **폴아웃 1·2**의 인터페이스 구조(화면 아래 콘솔 · 디스플레이 · 물리 버튼)를 **스타워즈 재질**(공화국 선체 패널 · 파란 홀로 화면 · 데이터패드 · 조종석 버튼)로 만든 HUD와 **배틀프론트 2** 스타일의 흰색 벡터 스킬 아이콘.
주인공은 클론 전쟁 갑옷을 입은 **아나킨 스카이워커**입니다.

- 장르: 디아블로식 액션 RPG (클릭 이동/공격, 스킬 트리, 능력치, 드롭)
- 배경: 크리스토프시스 외곽 오픈월드 (192×192 타일) — 공화국 전진 기지, 수정 평원, 고대 도시 폐허, 드로이드 공장
- 그래픽: 스타크래프트 1 / 디아블로 2 / C&C / **폴아웃 1·2**처럼 **3D 모델을 사전 렌더링한 픽셀 스프라이트** — 단, 외부 이미지 없이 로딩 시 브라우저에서 직접 렌더링. 폴아웃풍의 낡은 기계 질감(패널 이음선·리벳·긁힘·때), 깎인 모서리, 채도를 낮춘 따뜻하고 대비 강한 톤

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 빌드
npm run preview
```

첫 로딩 시 모든 캐릭터·오브젝트를 3D로 렌더링해 스프라이트 아틀라스를 굽습니다 (수 초 소요).

## 📱 휴대폰에서 플레이 (설치형 웹 앱)

이 게임은 **PWA(설치형 웹 앱)** 입니다. 휴대폰 브라우저에서 열고 홈 화면에 추가하면 아이콘으로 실행되는 전체 화면 앱이 되고, 한 번 연 뒤에는 오프라인에서도 실행됩니다.

1. **배포 (최초 1회)**: GitHub 저장소 → Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정.
   이후 이 브랜치에 푸시할 때마다 `.github/workflows/deploy-pages.yml`이 빌드해서 배포합니다.
   (이미 실패한 워크플로가 있으면 Actions 탭에서 **Re-run** 하세요.)
2. 휴대폰에서 `https://geroroy.github.io/Isometric-RPG/` 접속
3. **안드로이드(Chrome)**: 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
   **아이폰(Safari)**: 공유 버튼 → **홈 화면에 추가**
4. 홈 화면의 Clone Wars 아이콘으로 실행 → **가로 화면**으로 플레이

휴대폰 기본 화면 배율은 **갤럭시 S25 Ultra(가로)** 기준으로 맞춰져 있습니다 (세로로 약 240 게임 픽셀이 보이도록). 핀치나 − + 버튼으로 50%~250% 사이에서 조절하면 기기에 저장됩니다.

**태블릿에서 키보드·마우스로**: 블루투스 마우스를 연결하면 PC와 같은 조작(좌클릭 이동·공격, 우클릭 스킬, 휠 확대·축소, 단축키)과 PC용 HUD로 바뀝니다. 화면을 손으로 터치하면 터치 UI로, 다시 마우스를 쓰면 PC 모드로 돌아갑니다.

설치하지 않고 브라우저에서 바로 할 때는 시작 버튼을 누르면 자동으로 전체 화면이 됩니다 (안드로이드). 아이폰 Safari는 웹 페이지의 전체 화면을 지원하지 않으므로 홈 화면에 추가해서 실행하세요.

### 터치 조작

| 입력 | 동작 |
| --- | --- |
| 왼쪽 화면 드래그 | 가상 스틱으로 이동 (짧게 탭하면 그 위치로 이동 / 적을 탭하면 공격) |
| 공격 버튼 (오른쪽 아래) | 누르고 있으면 가장 가까운 드로이드를 계속 공격 |
| 스킬 버튼 탭 | 가까운 적에게 자동 조준해 시전 |
| 스킬 버튼 드래그 | 바닥에 조준선이 표시됨 → 손을 떼면 그 방향/위치로 시전 (포스 도약, LAAT 공습은 끄는 거리만큼) |
| 박타 버튼 | 생명력 회복 |
| NPC 탭 / 대화 버튼 | NPC 근처에서는 공격 버튼이 **대화** 버튼으로 바뀜 |
| 두 손가락 핀치 | 화면 확대·축소 (설정은 저장됨) |
| 오른쪽 위 버튼 | 스킬 · 정보 · 지도 · 설정 · − + 확대/축소 · 전체 화면 |
| 스킬 트리 | 스킬을 탭해 선택 → **투자** 또는 같은 스킬을 한 번 더 탭 · 숫자 버튼으로 스킬 버튼 슬롯 지정 |

## 조작 (PC)

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 (화면 기준 위·왼쪽·아래·오른쪽) |
| 좌클릭 (홀드) | 이동 / 적 공격 |
| Shift + 좌클릭 | 제자리 공격 |
| 우클릭 (홀드) | 지정 스킬 시전 (명령 카드의 **R** 슬롯) |
| 1 ~ 6 | 단축키 스킬 시전 |
| Q | 박타 주사기 |
| K / T | 스킬 트리 (S 별칭 제거) · 스킬 위에서 1~6 = 단축키 지정, 우클릭 = 우버튼 지정 |
| O | 설정 (초상화 사진 · 소리) |
| C | 캐릭터 능력치 (A 별칭은 이동 키와 겹쳐서 제거) |
| Tab | 자동 지도 · 미니맵 클릭 = 이동 |
| X | 광선검 켜기/끄기 (전투가 시작되면 자동 점화, 끝나고 6초 뒤 자동 소등, 꺼진 채로 공격하면 바로 점화) |
| P | 스타 카드 (퍽 장착 · 잠금 해제 · 강화) |
| V | 외형 갤러리 (정보 창의 '외형 갤러리' 버튼과 같음) |
| E / NPC 클릭 | 가까운 NPC와 대화 (숫자 키로 선택지, Esc로 종료) |
| F | 전체 화면 켜기/끄기 (오른쪽 위 ⛶ 버튼과 같음, Esc로도 해제) |
| 마우스 휠 / `-` `=` / `0` | 화면 확대·축소 / 기본 배율 (오른쪽 위 − + 버튼과 같음) |
| M / F1 | 음소거 / 조작법 |
| F9 | 개발자용: +5 레벨 (스킬 빠르게 테스트) |

초상화를 클릭하면 아나킨이 말합니다.

## 주요 기능 (M1)

- **아나킨 스카이워커**: 참고 이미지 기반 클론 전쟁 갑옷(건메탈 흉갑, 제다이 문장 폴드런, 앞이 트인 남색 태버드, 버건디 튜닉, 갈색 건틀릿·부츠) 로우폴리 모델 → 16방향 스프라이트 (2배 슈퍼샘플링)
  - 광선검은 **칼자루 위치 + 칼날 방향**으로 애니메이션하고 양팔을 IK로 붙여서, 휘두를 때도 두 손이 항상 칼자루를 잡음
  - 검식은 **에피소드 III의 젬 소**: 오른쪽 어깨 옆 양손 하이 가드, 기본 연격 = 오른쪽 위→왼쪽 아래 대각 베기 → 반대 대각 되베기(X) → 정수리 내려치기, 대각선으로 기울인 막기
  - 몸 뒤로 지나가는 칼날은 가려진 구간을 굽는 단계에서 계산해 빛 효과도 그 부분은 그리지 않음 (대각선 이동 시 광선검이 몸 위에 겹쳐 보이던 문제 해결)
- **3개 스킬 트리 · 18 스킬** (전부 구현)
  - 라이트세이버 전투 (Form V 젬 소/쉬엔): 세이버 연격, 쉬엔 반사, 젬 소 내려치기, 세이버 투척, 쉬엔 방벽, 선택받은 자의 분노
  - 포스: 포스 푸시, 포스 스피드, 포스 도약, 포스 예지, 포스 초크, 포스 리펄스
  - 501군단 지휘관: 클론 트루퍼 호출, 기계공의 손길, R2-D2 지원, 전술 지휘, 렉스 대위, LAAT 공습
- **블래스터 볼트 반사**: 드로이드의 볼트를 광선검으로 튕겨내고, 숙련되면 사수에게 되돌려 보냄
- **빛/어둠 게이지**: 어둠의 기술은 강하지만 게이지가 오르면 초상화의 눈이 시스의 노란색으로 변함
- 적: B1 전투 드로이드, B2 슈퍼 배틀 드로이드, 거점별 정예, 드로이드 공장 수호자
- 디아블로식 라이트맵 조명, 광선검 글로우/궤적, 파티클, 화면 흔들림
- **휴대폰 지원**: 가상 스틱 + 공격/스킬 버튼(드래그 조준), 모바일 HUD, 설치형 앱(PWA, 오프라인 캐시, 가로 고정)
- **HUD (폴아웃식 콘솔 × 공화국 하드웨어)**: 화면 아래 선체 패널 콘솔에 초상화 · 메시지 로그 · 포스 램프 · 스킬 소켓(쿨다운 숫자·RMB 표시) · HP/FP 숫자 카운터 · 빛/어둠 게이지 · 메뉴 버튼 · 레이더, 오른쪽 위 목표 추적(가장 가까운 거점 방향·거리), 스킬 트리 · 정보 · 지도 · 설정 · 스타 카드 전체 화면 메뉴(메뉴를 열면 일시정지)
- **사진 초상화**: 설정(⚙ / `O`)에서 원하는 사진을 고르면 HUD 초상화가 실사 사진이 됩니다(확대·위치 조절, 숨쉬는 듯한 움직임, 어둠 게이지에 따른 색 보정, 피격 시 붉은 번쩍임). 사진은 그 기기에만 저장됩니다. 배포본에 넣으려면 `public/portrait/anakin.jpg`로 두면 됩니다(사용 권한이 있는 사진만). 사진이 없으면 레퍼런스 구도로 그린 픽셀 아트 초상화가 나옵니다
- **NPC 상호작용** (공화국 전진 기지): 오비완 케노비 · 렉스 대위 · 아소카 타노 · 보급관 '체인' · R2-D2
  - 대화창(선택지, 일부 선택은 빛/어둠에 영향), 머리 위 이름표와 임무 표시(! 받을 임무 / ? 보고할 임무)
  - **임무**: 렉스(첫 거점 소탕 → B2 8기 → 공장 수호자), 아소카(홀로크론 2개 → 드로이드 60기 내기), 목표 패널에 진행도 표시
  - **상점**: 드로이드를 파괴하면 크레딧 획득 → 보급관에게 박타 주사기 · 광선검 집속 렌즈(피해 +6%) · 갑옷 보강판(생명력 +15)
  - 아소카와 대련(공격 속도 버프), R2-D2 수리(생명력·포스 회복), 오비완과 명상(어둠 감소)
- **시작 화면 (제다이: 서바이버 메인 메뉴 참고)**: 실제 게임 월드를 노을빛으로 물들인 채 천천히 흐르는 카메라 위에, 왼쪽 아래 조용한 텍스트 메뉴(선택된 항목만 크게, 점·대시 표시와 가는 선) · 공화국 문장과 작은 저작권 표기 · 오른쪽 아래 '선택' 키 안내. 마우스 오버 / ↑↓ · W/S로 고르고 Enter로 실행
- **무비 듀얼 #1 · 지오노시스의 결투 (아나킨 vs 두쿠)**: 시작 화면의 '무비 듀얼'에서 시작
  - 두쿠의 비밀 격납고(녹색 조명), 쓰러진 오비완, 곡선 손잡이 붉은 광선검의 두쿠(마카시: 한 손 찌르기·플릭·백핸드, 포스 번개)
  - **평정**: 막을 때마다 줄고 0이 되면 자세 붕괴 · **우클릭(폰: 막기 버튼) 홀드 = 막기**, 공격 직전에 막으면 **완벽한 흘리기**(슬로 모션 + 두쿠 비틀거림)
  - **칼날 겨루기**: 서로의 공격이 맞부딪히면 발생, 좌클릭/Space/공격 버튼 연타
  - 페이즈: 체력 60%에서 오비완이 광선검을 던져 줌 → **쌍검**, 25%에서 두쿠가 칼날 겨루기를 강요 · 대사는 화자 이름과 함께 영화식 자막 + 레터박스
  - 결과 화면: 승패, 등급(S/A/B/C), 시간 · 받은 피해 · 완벽한 흘리기 · 칼날 겨루기 승리
- 구운 스프라이트는 기기에 저장(IndexedDB)되어 두 번째 실행부터는 바로 시작 (모델이 바뀌면 자동으로 다시 구움)
- **스타워즈 오브젝트**: LAAT/i 건쉽(혹 모양 조종석, 처진 날개, 볼 터렛, 미사일 런처), AT-TE(앞뒤 차체 + 주름 연결부, 6다리, 매스 드라이버 캐논), AAT 잔해, 지오노시스 드로이드 공장(붉은 바위 첨탑), 크리스토프시스 수정 도시 폐허, 공화국 문장이 그려진 클론 기지 건물·착륙장·보급 상자, 분리주의 레이 실드 방벽·감시탑·CIS 문장 상자, 결투장의 지오노시스 바위 기둥
- **태블릿 + 블루투스 키보드·마우스** (갤럭시 탭 S11 울트라 기준): 마우스를 쓰면 PC 조작·HUD, 화면을 터치하면 터치 UI로 자동 전환, 시작 시 전체 화면
- **스타 카드 (퍽, 배틀프론트 2 방식)**: `P` 키 / 터치 메뉴 '카드'. 장착 슬롯 3개(레벨 1·5·10에 열림), 카드 12종, 등급 4단계(일반 I → 고급 II → 희귀 III → 에픽 IV). 드로이드를 파괴하거나(B1 1, B2 2, 정예 12) 거점 소탕(8)·임무 보고(30)로 **크래프팅 부품**을 모아 잠금 해제(40)·강화(60/120/220)
  - 카드 일러스트: `public/cards/<카드 id>.jpg`(또는 .png/.webp)에 두면 표시됩니다. 없으면 스킬 아이콘과 '일러스트 없음'이 나옵니다.
  - 카드 id: `aggressive`(공격적인 협상) · `shienMaster`(쉬엔의 숙련) · `forceAttune`(포스 조율) · `tenacity`(강철 의지) · `foresight`(위험 감지) · `heroicMight`(영웅의 기세) · `forceMastery`(포스 숙련) · `focus`(전투 집중) · `bactaPack`(박타 탄띠) · `droidSlayer`(드로이드 사냥꾼) · `legionBond`(501군단의 유대) · `darkAnger`(분노의 힘)
- **외형 갤러리 (배틀프론트 2 히어로 외형 방식)**: `V` 키 / 정보 창의 '외형 갤러리'. 외형 목록(등급 색: 일반 · 에픽 · 전설), 게임에 쓰이는 스프라이트 모음(대기 · 이동 · 공격 1~3 · 포스 · 투척 · 도약 · 막기 · 흘리기 · 피격 · 쓰러짐을 8방향으로 동시에 재생, 광선검 발광 포함), 시대 · 설명 · 포함 요소가 적힌 카드, 장착 버튼. 장착한 외형은 기기에 저장되고 스프라이트는 갤러리에서 처음 볼 때 한 번만 렌더링(이후 캐시). 무비 듀얼은 기본 외형을 유지합니다.
  - **501군단 장군** (일반): 클론 전쟁 갑옷 (기본)
  - **제다이 기사** (에픽): 에피소드 III 튜닉 — 검은 가죽 타바드, 갈색 튜닉의 V 여밈과 높은 속옷 깃, 넓은 오비와 파우치 달린 벨트, 종 모양 소매, 오른손(의수)의 긴 검은 장갑, 긴 부츠
  - **제다이 로브** (전설): 위 튜닉 + 앞이 트인 발목 길이 갈색 로브, 넓은 소매, 등에 늘어뜨린 두건
  - 두 에피소드 III 외형은 영화 헤어스타일(가운데 가르마, 얼굴을 감싸는 앞머리, 귀를 덮고 어깨까지 내려오는 웨이브, 밝은 갈색 하이라이트)과 오른쪽 눈 위 흉터를 씁니다.
- 기본 HUD 초상화: `public/portrait/anakin.jpg` (설정에서 고른 사진이 있으면 그것이 우선, '기본 초상화로' 버튼으로 되돌림)
- 절차적 지형(바이옴 블렌딩·디더링), 지역 배너, 자동 지도
- **폴아웃 구조 × 스타워즈 재질의 인터페이스**: 폴아웃 1·2의 배치(화면 아래 콘솔, 테두리 친 디스플레이, 누르는 버튼, 낡은 하드웨어)는 그대로 두고 재질을 클론 전쟁 공화국 것으로 — 붉은 공화국 줄무늬가 들어간 낡은 회색 선체 패널(이음선 · 리벳 · 벗겨진 도장 · 그을음), 파란 홀로 화면, 종이 대신 데이터패드, 백라이트 조종석 키, 호박색 LED 숫자, 파란 포스 표시등, 홀로테이블 지도, 홀로그램 통신처럼 보이는 대화 얼굴 화면, 스타워즈 로고 노란색 제목, Michroma(유로스타일 계열 조종석 글꼴) 라벨. 조작법 창(타이틀 '조작법' · F1 · 설정)
- **배틀프론트 2 스타일 아이콘**: 모든 스킬·카드·메뉴 아이콘을 흰색 벡터 실루엣으로 그림(`src/ui/icons.js`, 이미지 파일 없음)
- **광선검 효과음 (오리지널 합성)**: `tools/saber_sfx.py`(numpy · scipy)가 영화 음원 없이 직접 합성한 WAV — 험 루프 · 버즈 · 스윙 3종(도플러) · 충돌 · 켜기 · 끄기 → `public/audio/sfx/saber_*.wav`. 기본 주파수 · 디튠 · 버즈 양 등은 스크립트 맨 위 변수로 조절하고 `python3 tools/saber_sfx.py`로 다시 만들면 됩니다.
- 그 밖의 효과음은 WebAudio 절차적 합성 (WAV가 없으면 광선검도 합성음으로 대체)
- **사운드 뱅크 슬롯**: `public/audio/index.json`에 직접 준비한(사용 권한이 있는) 효과음·대사 음성 파일을 등록하면 합성음 대신 재생되고, 대사는 자막과 함께 상황에 맞게 나옵니다 → [`public/audio/README.md`](public/audio/README.md)

## 구조

```
src/
  main.js               부트스트랩 & 게임 루프
  core/                 수학/노이즈, 아이소 투영, 입력, 오디오
  gfx/
    baker.js            3D → 스프라이트 베이커 (트림, 디더링, 외곽선, 아틀라스 패킹, 마커)
    models/             Three.js 모델: 리그, 캐릭터, 애니메이션, 소품
    assets.js           로딩 시 전체 베이킹
    terrain.js          청크 단위 픽셀 지형
    renderer.js         깊이 정렬, 라이트맵, 가산 글로우
    portrait.js         HUD 초상화: 사진 모드 + 픽셀 아트 대체 초상화
    fx.js               파티클/충격파/번개/텍스트
  world/                월드 생성, A* 길찾기
  game/                 게임 규칙, 유닛 AI, 스킬 트리, 대사, NPC·대화·임무, 무비 듀얼(duel.js)
  ui/                   콘솔 HUD·메뉴·레이더(skin.js: 선체 패널 · 홀로 화면 · 데이터패드 질감), 대화창, 외형 갤러리(appearance.js), 듀얼 HUD, 사진 초상화, 터치·확대·전체 화면, 벡터 아이콘
tools/saber_sfx.py      광선검 효과음 합성기 (numpy · scipy → public/audio/sfx/*.wav)
debug.html              스프라이트 시트 확인용 (?m=anakin|anakin_tunic|anakin_robe|anakinDual|dooku|obiwan|ahsoka|quartermaster|clone|rex|b1|b2|r2, &only=애니메이션, &dirs=방향)
debug-portrait.html     픽셀 초상화 변형(배경·어둠·대사) 확인용
```
