# CLONE WARS: 선택받은 자 (Isometric RPG)

스타워즈 **클론 전쟁**을 배경으로 한 올드스쿨 아이소메트릭 핵 앤 슬래시 RPG 프로토타입.
디아블로 2의 조작/성장 구조에, **폴아웃 1·2**의 인터페이스 구조(화면 아래 콘솔 · 디스플레이 · 물리 버튼)를 **스타워즈 재질**(공화국 선체 패널 · 파란 홀로 화면 · 데이터패드 · 조종석 버튼)로 만든 HUD와 **배틀프론트 2** 스타일의 흰색 벡터 스킬 아이콘.
주인공은 클론 전쟁 갑옷을 입은 **아나킨 스카이워커**입니다.

- 장르: 디아블로식 액션 RPG (클릭 이동/공격, 스킬 트리, 능력치, 드롭)
- 배경: 크리스토프시스 외곽 오픈월드 (192×192 타일) — 공화국 전진 기지, 수정 평원, 고대 도시 폐허, 드로이드 공장
- 그래픽: 스타크래프트 1 / 디아블로 2 / C&C / **폴아웃 1·2**처럼 **3D 모델을 사전 렌더링한 픽셀 스프라이트** — 단, 외부 이미지 없이 로딩 시 브라우저에서 직접 렌더링. 폴아웃풍의 낡은 기계 질감(패널 이음선·리벳·긁힘·때), 깎인 모서리, 채도를 낮춘 따뜻하고 대비 강한 톤

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 빌드
npm run preview
```

## 📱 휴대폰에서 플레이 (설치형 웹 앱)

이 게임은 **PWA(설치형 웹 앱)** 입니다. 휴대폰 브라우저에서 열고 홈 화면에 추가하면 아이콘으로 실행되는 전체 화면 앱이 되고, 한 번 연 뒤에는 오프라인에서도 실행됩니다.

1. **배포 (최초 1회)**: GitHub 저장소 → Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정.
   이후 이 브랜치에 푸시할 때마다 `.github/workflows/deploy-pages.yml`이 빌드해서 배포합니다.
   (이미 실패한 워크플로가 있으면 Actions 탭에서 **Re-run** 하세요.)
2. 휴대폰에서 `https://geroroy.github.io/Isometric-RPG/` 접속
3. **안드로이드(Chrome)**: 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
   **아이폰(Safari)**: 공유 버튼 → **홈 화면에 추가**
4. 홈 화면의 Clone Wars 아이콘으로 실행 → **가로 화면**으로 플레이

휴대폰 기본 화면 배율은 **갤럭시 S25 Ultra(가로)** 기준으로 맞춰져 있습니다 (세로로 약 240 게임 픽셀이 보이도록). 핀치나 − + 버튼으로 50%~250% 사이에서 조절하면 기기에 저장됩니다.

**태블릿에서 키보드·마우스로**: 블루투스 마우스를 연결하면 PC와 같은 조작(좌클릭 이동·공격, 우클릭 스킬, 휠 확대·축소, 단축키)과 PC용 HUD로 바뀝니다. 화면을 손으로 터치하면 터치 UI로, 다시 마우스를 쓰면 PC 모드로 돌아갑니다.

설치하지 않고 브라우저에서 바로 할 때는 시작 버튼을 누르면 자동으로 전체 화면이 됩니다 (안드로이드). 아이폰 Safari는 웹 페이지의 전체 화면을 지원하지 않으므로 홈 화면에 추가해서 실행하세요.

| 입력 | 동작 |

| 왼쪽 화면 드래그 | 가상 스틱으로 이동 (짧게 탭하면 그 위치로 이동 / 적을 탭하면 공격) |
| 공격 버튼 (오른쪽 아래) | 누르고 있으면 가장 가까운 드로이드를 계속 공격 |

| 박타 버튼 | 생명력 회복 |
| NPC 탭 / 대화 버튼 | NPC 근처에서는 공격 버튼이 **대화** 버튼으로 바뀜 |
| 두 손가락 핀치 | 화면 확대·축소 (설정은 저장됨) |
| 오른쪽 위 버튼 | 스킬 · 정보 · 지도 · 설정 · − + 확대/축소 · 전체 화면 |
| 스킬 트리 | 스킬을 탭해 선택 → **투자** 또는 같은 스킬을 한 번 더 탭 · 숫자 버튼으로 스킬 버튼 슬롯 지정 |

## 주요 기능 (M1)

- **아나킨 스카이워커**: 참고 이미지 기반 클론 전쟁 갑옷(건메탈 흉갑, 제다이 문장 폴드런, 앞이 트인 남색 태버드, 버건디 튜닉, 갈색 건틀릿·부츠) 로우폴리 모델 → 16방향 스프라이트 (2배 슈퍼샘플링)
  - 광선검은 **칼자루 위치 + 칼날 방향**으로 애니메이션하고 양팔을 IK로 붙여서, 휘두를 때도 두 손이 항상 칼자루를 잡음
  - 검식은 **에피소드 III의 젬 소**: 오른쪽 어깨 옆 양손 하이 가드, 기본 연격 = 오른쪽 위→왼쪽 아래 대각 베기 → 반대 대각 되베기(X) → 정수리 내려치기, 대각선으로 기울인 막기
  - 몸 뒤로 지나가는 칼날은 가려진 구간을 굽는 단계에서 계산해 빛 효과도 그 부분은 그리지 않음 (대각선 이동 시 광선검이 몸 위에 겹쳐 보이던 문제 해결)
- **3개 스킬 트리 · 18 스킬** (전부 구현)
  - 라이트세이버 전투 (Form V 젬 소/쉬엔): 세이버 연격, 쉬엔 반사, 젬 소 내려치기, 세이버 투척, 쉬엔 방벽, 선택받은 자의 분노
  - 포스: 포스 푸시, 포스 스피드, 포스 도약, 포스 예지, 포스 초크, 포스 리펄스
  - 501군단 지휘관: 클론 트루퍼 호출, 기계공의 손길, R2-D2 지원, 전술 지휘, 렉스 대위, LAAT 공습
- **블래스터 볼트 반사**: 드로이드의 볼트를 광선검으로 튕겨내고, 숙련되면 사수에게 되돌려 보냄
- **빛/어둠 게이지**: 어둠의 기술은 강하지만 게이지가 오르면 초상화의 눈이 시스의 노란색으로 변함
- 적: B1 전투 드로이드, B2 슈퍼 배틀 드로이드, 거점별 정예, 드로이드 공장 수호자
- 디아블로식 라이트맵 조명, 광선검 글로우/궤적, 파티클, 화면 흔들림
- **휴대폰 지원**: 가상 스틱 + 공격/스킬 버튼(드래그 조준), 모바일 HUD, 설치형 앱(PWA, 오프라인 캐시, 가로 고정)
- **HUD (폴아웃식 콘솔 × 공화국 하드웨어)**: 화면 아래 선체 패널 콘솔에 초상화 · 메시지 로그 · 포스 램프 · 스킬 소켓(쿨다운 숫자·RMB 표시) · HP/FP 숫자 카운터 · 빛/어둠 게이지 · 메뉴 버튼 · 레이더, 오른쪽 위 목표 추적(가장 가까운 거점 방향·거리), 스킬 트리 · 정보 · 지도 · 설정 · 스타 카드 전체 화면 메뉴(메뉴를 열면 일시정지)
- **사진 초상화**: 설정(⚙ / `O`)에서 원하는 사진을 고르면 HUD 초상화가 실사 사진이 됩니다(확대·위치 조절, 숨쉬는 듯한 움직임, 어둠 게이지에 따른 색 보정, 피격 시 붉은 번쩍임). 사진은 그 기기에만 저장됩니다. 배포본에 넣으려면 `public/portrait/anakin.jpg`로 두면 됩니다(사용 권한이 있는 사진만). 사진이 없으면 레퍼런스 구도로 그린 픽셀 아트 초상화가 나옵니다
- **메인 허브 · 코러산트 시내** (게임 시작 장소, 오리지널 레이아웃): 한 도시의 두 층이 바닥이 보이지 않는 낭떠러지 위에 겹쳐 있음
  - **상층 플라자**: 밝은 돌바닥과 황동 장식, 화분의 나무, 계단식 고층 타워, 낮처럼 밝은 조명 · 제다이 착륙장(아나킨의 스타파이터, 오비완 · 아소카 · 렉스 · 보급관 · R2-D2)
  - **언더시티**: 터보리프트로 내려가는 하층. Blender로 만든 에셋(`tools/sprites/build_city_assets.py`)으로 지음 — 2층 칸티나 '녹슨 등불'(앰버 빛이 새는 출입구, 주황 · 분홍 원형 네온, 발코니, 지붕 환기구), 창마다 다른 빛의 고층 공동주택, 줄무늬 차양의 노점, 홀로그램 광고 탑, 세워 둔 스피더 바이크, 상자 · 연료통 · 증기 배출구 · 드로이드 잔해 · 쓰레기통 · 깜빡이는 배전함. 바닥은 이음매 없이 이어지는 균열 난 듀라크리트 판과 배수 격자, 네온이 비치는 젖은 자국
  - **살아 있는 도시** (`src/data/cityLife.json` → `src/game/citizens.js`, `cityLife.js`): 50여 명이 저마다 일과(장소 목록 + 머무는 시간 + 할 일)를 따라 경로로 이동 — 노동자는 공장 하역장 → 시장 → 칸티나 앞 → 집, 노점상은 자기 가게 앞, 떠돌이는 골목에 앉았다가 빛이 드는 곳으로. 말은 말풍선으로
  - **코러산트 경비대**(붉은 표식의 클론)가 순찰 경로를 돌다 아나킨이 가까이 오면 멈춰 신분 확인 말풍선. 노점상은 지나가는 아나킨을 부르고, 광선검을 켜면 주변 사람들이 비명을 지르며 달아나고 멀리 있는 사람은 수군거림 (도시에서는 광선검을 끈 채 시작)
  - **무작위 사건** (30초~2분 간격, 아나킨 근처): 소매치기(달아나는 도둑을 붙잡으면 지갑을 돌려주고 +20 크레딧), 싸움(구경꾼이 모이고, 아나킨이 다가가거나 경비대가 오면 해산), 경비대의 검문
  - **배경의 움직임**: 낭떠러지 사이의 공중 교통, 언더시티 머리 위로 지나가며 거리에 빛을 쓸고 가는 스피더, 따로 깜빡이는 네온(스프라이트 JSON의 설정), 환기구 · 배출구의 증기, 몇 초마다 바뀌는 홀로그램 광고, 물방울이 떨어져 파문이 이는 웅덩이, 떠 있는 스피더 바이크의 흔들림
  - **소리** (`tools/city_ambience.py`로 합성, `src/core/ambience.js`): 층마다 배경음 레이어(하층: 기계 웅웅거림과 물방울, 상층: 바람) + 먼 스피더 + 외계어 웅성거림(시장에서 커짐). 칸티나 밴드(오리지널 곡)는 문에 가까울수록 커지고 또렷해지며 배경 음악이 그 아래로 줄어듦, 가까운 증기 배출구의 쉭 소리. 설정 → 소리의 '환경음' 볼륨

  - 칼날 겨루기: 지글거리는 루프가 이어지고 연타할 때마다 더 세게 갈림, 끝날 때 무거운 충돌
  - 드로이드 타격 3종, 치명타는 충돌 레이어 추가 · 모든 효과음은 화면 위치에 따라 좌우 패닝
  - 이전의 순수 합성 버전은 `tools/saber_sfx.py`로 다시 만들 수 있습니다(실행하면 index.json의 광선검 항목을 덮어씀)
- **상황별 배경 음악**: 아나킨 테마 모음집에서 잘라 낸 13개 곡을 상황에 맞춰 교차 페이드(`src/core/music.js`). 시작 화면 · 필드 정찰 · 공화국 기지 · 전투 · 정예 드로이드/공장 보스 · 두쿠 결투 · 결투 승리(엔딩 크레디트)는 반복 곡, 전투 종료(드로이드를 쓰러뜨렸을 때) · 사망 · 어둠 게이지 60 돌파는 짧은 스팅(배경 곡을 잠시 낮췄다가 되돌림). 정찰 곡은 전투가 끝나면 멈췄던 곳부터 이어지고 전투 곡은 매번 처음부터. 브라우저 자동 재생 제한 때문에 첫 클릭/키 입력부터 재생. 곡 배정과 구간은 `tools/cut_music.py`(ffmpeg, 원본 m4a → Opus .webm)에서 바꿀 수 있습니다.
- **모스 아이슬리 칸티나 · 주크박스 (울트라킬 · 데빌 메이 크라이 5 방식)**: 기지 북문 밖의 타투인풍 칸티나(흰 흙벽 돔, 아치형 출입구, 수분 증발기) 앞에서 클루 혼을 부는 비스족 **피그린 단**에게 말을 걸어 주크박스를 엽니다.
  - 게임 속 배경 음악 13곡은 처음 들을 때 해금(아직 못 들은 곡은 '???'와 들을 수 있는 상황 힌트), 해금하면 콘솔에 알림
  - 해금한 곡 재생 · 일시정지 · 이전/다음 · 한 곡 반복/전체 재생. 칸티나를 나가도 계속 재생되고, 화면 왼쪽 위 ♪ 표시를 누르면 멈추고 상황별 음악으로 돌아감
  - **상황별 배경 음악 지정**: 시작 화면 · 필드 · 기지 · 전투 · 보스 · 결투 · 결투 승리 · 전투 종료 · 사망 · 어둠으로 — 원하는 해금 곡을 지정하면 그때부터 그 곡이 나옴(기기에 저장)
- **볼륨 설정**: 설정 → 소리에서 전체 · 음악 · 효과음 · 광선검 험 · 음성을 따로 조절(기기에 저장), `M`으로 음소거
- **디버그 모드** (`` ` `` 키 / 설정 → 개발자): 모든 스킬 최대 레벨 · 모든 음악 해금(주크박스) · 모든 스타 카드 최고 등급 · 음악 해금 초기화, 레벨 +5 · 스킬/능력치 포인트 · 크레딧 · 부품 · 생명력/포스/박타 가득, 무적 · 포스 무한 · 재사용 대기시간 없음 스위치, 주변 적 처치 · 어둠 게이지 0, 지도 전체 공개 · 기지/칸티나/가장 가까운 거점/공장으로 순간 이동
- 그 밖의 효과음은 WebAudio 절차적 합성 (WAV가 없으면 광선검도 합성음으로 대체)
- **사운드 뱅크 슬롯**: `public/audio/index.json`에 직접 준비한(사용 권한이 있는) 효과음·대사 음성 파일을 등록하면 합성음 대신 재생되고, 대사는 자막과 함께 상황에 맞게 나옵니다 → [`public/audio/README.md`](public/audio/README.md)
